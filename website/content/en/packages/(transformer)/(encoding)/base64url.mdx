## Overview [#overview]

`@unikvs/base64url` is a Transformer plugin that converts byte sequences to bytes representing URL-safe base64 (base64url) strings. <Badge>Transformer</Badge>

Use it for values embedded in URLs or file names, or for storing into destinations that only hold text.

- The 64 characters used are RFC 4648 §5 `A-Z`, `a-z`, `0-9`, `-`, and `_`.
- It is always open. No `open` or `close` is needed; `isOpen` always returns `true` and `name` always returns `"Base64Url"`.
- It runs on Node.js, Bun, and browsers with no runtime-specific behavior differences.

:::tip
To store smaller, consider [`@unikvs/compression`](/packages/compression); to detect corruption or tampering, consider [`@unikvs/checksum`](/packages/checksum). This package provides neither compression nor verification.
:::

Install with the following command.

```package-install
npm install @unikvs/base64url
```

## Usage [#usage]

`Base64Url` implements ITransformer. Pass it to UniKvs via transform().

```ts
import { Base64Url } from "@unikvs/base64url";
```

The constructor arguments are as follows.

<TypeTable
  type={{
    options: {
      type: "Base64UrlOptions",
      description: "Settings for encoding and padding. Runs with defaults when omitted.",
    },
    "options.encoder": {
      type: "FastUtf8",
      description: "The encoder that converts base64url text to bytes. Specify it only when you need a replacement.",
    },
    "options.decoder": {
      type: "FastUtf8",
      description: "The decoder that converts bytes to base64url text. Specify it only when you need a replacement.",
    },
    "options.padding": {
      type: "boolean",
      default: "false",
      description: "Whether to append `=` at the end. `decode` accepts input with or without it.",
    },
  }}
/>

Below is an example of saving a written value as base64url and restoring it to the original bytes on read.

```ts
import { Base64Url } from "@unikvs/base64url";
import { Memory } from "@unikvs/memory";
import UniKvs, { type PlainValue } from "unikvs";

const kvs = UniKvs.config<{ data: PlainValue<Uint8Array<ArrayBuffer>> }>()
  .transform(new Base64Url())
  .persist(new Memory())
  .create();

await kvs.open();

const input = new TextEncoder().encode("foobar");
await kvs.set("data", input);

const output = await kvs.get("data");

await kvs.close();
```

## Data Types [#data-types]

| Method | Input | Output |
| --- | --- | --- |
| `encode` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |
| `decode` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |
| `getEncodable` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |
| `getDecodable` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |

- `encode` converts bytes to bytes (UTF-8) representing RFC 4648 §5 base64url text.
- `decode` restores bytes representing base64url text to the original bytes.
- The converted size is about 1.37 times the original size.
- By default it omits trailing `=`; with `padding: true` it outputs the canonical form padded with `=`.
- Empty input produces empty output.

- Chunks are simply concatenated with no delimiter.
- `getEncodable` converts in 3-byte units, holding a remainder (1–2 bytes) spanning chunk boundaries internally and joining it with the next chunk.
- Whether trailing `=` is present is determined when the stream ends.
- `getDecodable` restores in 4-character units, holding incomplete characters internally and joining them with the next chunk.
- An empty stream and zero-length chunks produce no values.

## Errors [#errors]

This package throws the following errors.

### Base64UrlDecodeError

#### Meaning

The input cannot be interpreted as base64url. Caused by stray `+`, `/`, or whitespace, misplaced `=`, or a length with remainder 1 when divided by 4.

#### How to handle

Check that the input is a run of base64url characters (`A-Z`, `a-z`, `0-9`, `-`, `_`, and trailing `=`). When you need standard base64, convert it on the caller side or use `@unikvs/base64`.

#### Example

Below is an example of catching `Base64UrlDecodeError`.

```ts
import { Base64Url, Base64UrlDecodeError } from "@unikvs/base64url";

const base64url = new Base64Url();

try {
  base64url.decode({ data: new TextEncoder().encode("ab+c") });
} catch (error) {
  if (error instanceof Base64UrlDecodeError) {
    console.log("Cannot be interpreted as base64url.");
  } else {
    throw error;
  }
}
```

Bytes that are invalid as UTF-8 propagate as a native `TypeError`, not as `Base64UrlDecodeError`.
