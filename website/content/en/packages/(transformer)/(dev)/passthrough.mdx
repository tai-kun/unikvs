## Overview [#overview]

`@unikvs/passthrough` is a Transformer plugin that passes input through without any conversion. <Badge>Transformer</Badge>

Use it when you want to toggle transformation on and off with a condition without changing the pipeline structure.

- `encode` and `decode` return the received data as is.
- It is always open. No `open` or `close` is needed; `isOpen` always returns `true` and `name` always returns `"PassThrough"`.

:::note
To record logs, use [`@unikvs/debug`](/packages/debug) instead. This package neither outputs logs nor reads variables.
:::

Install with the following command.

```package-install
npm install @unikvs/passthrough
```

## Usage [#usage]

`PassThrough` implements ITransformer. Pass it to UniKvs via transform().

```ts
import { PassThrough } from "@unikvs/passthrough";
```

Below is an example of saving a value as is without conversion.

```ts
import { Memory } from "@unikvs/memory";
import { PassThrough } from "@unikvs/passthrough";
import { UniKvs, type PlainValue } from "unikvs";

const kvs = UniKvs.config<{ greeting: PlainValue<string> }>()
  .transform(new PassThrough())
  .persist(new Memory())
  .create();

await kvs.open();

await kvs.set("greeting", "hello");
const greeting = await kvs.get("greeting");

await kvs.close();
```

## Data Types [#data-types]

| Method         | Input   | Output  |
| -------------- | ------- | ------- |
| `encode`       | `TData` | `TData` |
| `decode`       | `TData` | `TData` |
| `getEncodable` | `any`   | `any`   |
| `getDecodable` | `any`   | `any`   |

- `encode` and `decode` return data of any type as is.
- `getEncodable` and `getDecodable` return a `TransformStream` that passes chunks through as is.
- It affects neither data contents nor chunk splitting.

- Chunks pass through simply with no delimiter.
- Chunk boundaries and references do not change.
- An empty stream completes while staying empty.

## Errors [#errors]

This package has no package-specific errors. Since it converts no data, stored values do not change when it is used alone.
