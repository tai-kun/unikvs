## Overview [#overview]

`@unikvs/debug` is a Transformer plugin that passes read/write data through untouched while recording the operation kind, target key, and data information. <Badge>Transformer</Badge>

When used via `UniKvs`, it leaves a log of "which operation read or wrote data for which key."

- It performs no data conversion.
- It is always open. No `open` or `close` is needed; `isOpen` always returns `true` and `name` always returns `"Debug"`.
- The logger category is `["unikvs", "@unikvs/debug"]` and the level is `debug`.

:::tip
By default it records only the type and size of data, not the contents. Use `getDebugInfo` when you need the contents.
:::

Install with the following command.

```package-install
npm install @unikvs/debug @logtape/logtape
```

## Usage [#usage]

`Debug` implements ITransformer. Pass it to UniKvs via transform().

```ts
import { Debug } from "@unikvs/debug";
```

The constructor arguments are as follows.

<TypeTable
  type={{
    options: {
      type: "DebugOptions",
      description: "Settings for narrowing the recorded targets and adding extra information. Records everything when omitted.",
    },
    "options.keyFilter": {
      type: "(key: string) => boolean",
      description: "Records only keys for which this returns `true`.",
    },
    "options.actionFilter": {
      type: "(action: string) => boolean",
      description: "Records only operations for which this returns `true`.",
    },
    "options.getDebugInfo": {
      type: "(args: DebugInfoArgs) => Record<string, unknown>",
      description: "Returns additional debug information. The return value is spread into the log properties.",
    },
  }}
/>

Below is an example of saving a value while recording reads and writes to the console.

```ts
import { Debug } from "@unikvs/debug";
import { Memory } from "@unikvs/memory";
import { configureSync, getConsoleSink } from "@logtape/logtape";
import { UniKvs, type PlainValue } from "unikvs";

configureSync({
  sinks: { console: getConsoleSink() },
  loggers: [
    {
      category: ["unikvs", "@unikvs/debug"],
      sinks: ["console"],
      lowestLevel: "debug",
    },
  ],
});

const kvs = UniKvs.config<{ greeting: PlainValue<string> }>()
  .transform(new Debug())
  .persist(new Memory())
  .create();

await kvs.open();

await kvs.set("greeting", "hello");
const greeting = await kvs.get("greeting");

await kvs.close();
```

## Data Types [#data-types]

| Method | Input | Output |
| --- | --- | --- |
| `encode` | `unknown` | `unknown` |
| `decode` | `unknown` | `unknown` |
| `getEncodable` | `unknown` | `unknown` |
| `getDecodable` | `unknown` | `unknown` |

- `encode` and `decode` return the input as is.
- `getEncodable` and `getDecodable` pass chunks through as is.
- It performs no data conversion; it reads the `unikvs:action` and `unikvs:key` variables and records them to LogTape.
- Data without both in `vars` is not recorded.

- Chunks pass through simply with no delimiter.
- `set` and `stream` of stream values emit one log per chunk, and filters also apply per chunk.
- Huge streams produce many logs, so narrow them down with `keyFilter` or `actionFilter`.

## Errors [#errors]

This package has no package-specific errors. LogTape configuration is additionally required to display logs; without it, no error is thrown and logs are output nowhere.
