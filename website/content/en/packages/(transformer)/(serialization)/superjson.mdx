## Overview [#overview]

`@unikvs/superjson` is a Transformer plugin that serializes any value with SuperJSON. <Badge>Transformer</Badge>

Use it to store `Date`, `Map`, `Set`, `BigInt`, `undefined`, and circular references — lost in plain JSON — with types preserved.

- It wraps [SuperJSON](https://github.com/blitz-js/superjson) to fit `ITransformer`.
- It is always open. No `open` or `close` is needed; `isOpen` always returns `true` and `name` always returns `"Superjson"`.
- Since the storage format is based on JSON, contents can be inspected as text.

:::note
When plain JSON is enough, consider [`@unikvs/json`](/packages/json); to store smaller in binary form, consider [`@unikvs/cbor`](/packages/cbor).
:::

Install with the following command.

```package-install
npm install @unikvs/superjson
```

## Usage [#usage]

`Superjson` implements ITransformer. Pass it to UniKvs via transform().

```ts
import { Superjson } from "@unikvs/superjson";
```

Below is an example of saving a value containing `Date` and `Set` as SuperJSON and restoring it with types preserved.

```ts
import { Superjson } from "@unikvs/superjson";
import { Memory } from "@unikvs/memory";
import UniKvs, { type PlainValue } from "unikvs";

type Profile = {
  name: string;
  joinedAt: Date;
  tags: Set<string>;
};

const kvs = UniKvs.config<{ profile: PlainValue<Profile> }>()
  .connect(new Superjson())
  .persist(new Memory())
  .create();

await kvs.open();

await kvs.set("profile", {
  name: "tai-kun",
  joinedAt: new Date("2024-01-02T03:04:05.678Z"),
  tags: new Set(["typescript", "kvs"]),
});

const profile = await kvs.get("profile");

await kvs.close();
```

## Data Types [#data-types]

| Method         | Input                     | Output                    |
| -------------- | ------------------------- | ------------------------- |
| `encode`       | `unknown`                 | `Uint8Array<ArrayBuffer>` |
| `decode`       | `Uint8Array<ArrayBuffer>` | `unknown`                 |
| `getEncodable` | `unknown`                 | `Uint8Array<ArrayBuffer>` |
| `getDecodable` | `Uint8Array<ArrayBuffer>` | `unknown`                 |

- `encode` converts any value to bytes (UTF-8) of a SuperJSON payload.
- `decode` restores bytes of a payload to a value.
- Keeps `Date`, `Map`, `Set`, `BigInt`, `undefined`, circular references, special numbers (`NaN`, `Infinity`, `-Infinity`, `-0`), typed arrays, `RegExp`, `URL`, and `Error` with type information.
- Functions and symbols are not kept; nested ones are removed.
- Class instances become plain objects.

- Chunks are joined with newline (`\n`) delimiters.
- `getEncodable` converts one input chunk as one SuperJSON payload and outputs it with a trailing `\n`.
- `getDecodable` restores one value per `\n`, stripping trailing `\r` and ignoring empty lines.
- The last line is processed even without a trailing newline, and chunk boundaries at arbitrary positions are restored.
- An empty stream outputs no values.

## Errors [#errors]

This package throws the following errors.

### SuperjsonUnsupportedValueError

#### Meaning

The root value is a function or a symbol; passing it as is converts it to `"{}"` and loses the original value. `meta.type` holds `"function"` or `"symbol"`.

#### How to handle

Save a value that contains no functions or symbols.

#### Example

Below is an example of catching `SuperjsonUnsupportedValueError`.

```ts
import { Superjson, SuperjsonUnsupportedValueError } from "@unikvs/superjson";

const superjson = new Superjson();

try {
  superjson.encode({ data: () => 1 });
} catch (error) {
  if (error instanceof SuperjsonUnsupportedValueError) {
    console.log(error.meta.type);
  } else {
    throw error;
  }
}
```

Corrupted payloads propagate as native errors. They become `SyntaxError` for empty bytes or lines that cannot be interpreted as JSON, and `TypeError` for bytes that cannot be interpreted as UTF-8.
