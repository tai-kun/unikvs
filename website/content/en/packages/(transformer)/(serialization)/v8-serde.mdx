## Overview [#overview]

`@unikvs/v8-serde` is a Transformer plugin that converts JavaScript values to bytes with Node.js `v8.serialize`. <Badge>Transformer</Badge> <Badge variant="warning">Node.js only</Badge>

It converts values handled by Structured Clone with a native implementation at high speed, for snapshots and caches shared between Node.js processes.

- `encode`, `decode`, `getEncodable`, and `getDecodable` are all asynchronous; call them with `await`.
- It is always open. No `open` or `close` is needed; `isOpen` always returns `true` and `name` always returns `"V8Serde"`.
- Since the storage format is V8-specific, it is not compatible with other runtimes or other languages.

:::note
To interoperate in a standard binary format, consider [`@unikvs/cbor`](/packages/cbor); to inspect contents as text, consider [`@unikvs/json`](/packages/json) or [`@unikvs/superjson`](/packages/superjson).
:::

Install with the following command.

```package-install
npm install @unikvs/v8-serde
```

## Usage [#usage]

`V8Serde` implements ITransformer. Pass it to UniKvs via transform().

```ts
import { V8Serde } from "@unikvs/v8-serde";
```

Below is an example of saving a value containing a `Map` as bytes and restoring it to the original value.

```ts
import { Memory } from "@unikvs/memory";
import { V8Serde } from "@unikvs/v8-serde";
import UniKvs, { type PlainValue } from "unikvs";

type Snapshot = {
  createdAt: Date;
  counts: Map<string, number>;
};

const kvs = UniKvs.config<{ snapshot: PlainValue<Snapshot> }>()
  .transform(new V8Serde())
  .persist(new Memory())
  .create();

await kvs.open();

await kvs.set("snapshot", {
  createdAt: new Date("2024-01-02T03:04:05.678Z"),
  counts: new Map([["read", 1]]),
});

const restored = await kvs.get("snapshot");

await kvs.close();
```

## Data Types [#data-types]

| Method         | Input                     | Output                                                       |
| -------------- | ------------------------- | ------------------------------------------------------------ |
| `encode`       | `unknown`                 | `Promise<Uint8Array<ArrayBuffer>>`                           |
| `decode`       | `Uint8Array<ArrayBuffer>` | `Promise<unknown>`                                           |
| `getEncodable` | `unknown`                 | `Promise<TransformStream<unknown, Uint8Array<ArrayBuffer>>>` |
| `getDecodable` | `Uint8Array<ArrayBuffer>` | `Promise<TransformStream<Uint8Array<ArrayBuffer>, unknown>>` |

- `encode` converts any value to `v8.serialize` bytes.
- `decode` restores bytes to a value.
- Supports `null`, booleans, numbers (including `-0`), `bigint`, strings, arrays, plain objects, `Date`, `Map`, `Set`, typed arrays, `ArrayBuffer`, `DataView`, `Buffer`, `RegExp`, `Error`, and circular references.
- Functions, symbols, `WeakMap`, `WeakSet`, `Promise`, and `SharedArrayBuffer` cannot be converted.

- Chunks are simply concatenated with a length prefix.
- `getEncodable` converts each input chunk independently as one value, emitting the 4-byte length and body in order.
- `getDecodable` emits a value as soon as one value completes, emitting completed ones in order when a single chunk contains multiple values.
- A truncated value is held internally and joined with the next chunk.
- An empty stream and zero-length chunks produce no values.

## Errors [#errors]

This package throws the following errors.

### V8SerdeEncodeError

#### Meaning

The value cannot be converted to bytes. Caused by unsupported values such as functions or symbols, or by exceeding the payload length limit. The original error is kept in `cause`.

#### How to handle

Save without including unsupported values.

#### Example

Below is an example of catching `V8SerdeEncodeError`.

```ts
import { V8Serde, V8SerdeEncodeError } from "@unikvs/v8-serde";

const v8serde = new V8Serde();

try {
  await v8serde.encode({ data: () => 1 });
} catch (error) {
  if (error instanceof V8SerdeEncodeError) {
    console.log(error.cause);
  } else {
    throw error;
  }
}
```

### V8SerdeDecodeError

#### Meaning

The bytes cannot be interpreted as a value. Caused by an invalid format or incomplete data at stream end. The original error is kept in `cause`.

#### How to handle

Check that the input is the output of this package's `encode`, or a combination of `getEncodable` and `getDecodable`.

#### Example

Below is an example of catching `V8SerdeDecodeError`.

```ts
import { V8Serde, V8SerdeDecodeError } from "@unikvs/v8-serde";

const v8serde = new V8Serde();

try {
  await v8serde.decode({ data: new Uint8Array(0) });
} catch (error) {
  if (error instanceof V8SerdeDecodeError) {
    console.log(error.cause);
  } else {
    throw error;
  }
}
```

### UnsupportedRuntimeError

#### Meaning

It was used on a runtime other than Node.js. A shared error from `@unikvs/core`.

#### How to handle

Run it on Node.js, or use `@unikvs/cbor`, `@unikvs/json`, or `@unikvs/superjson`, which also run on other runtimes.
