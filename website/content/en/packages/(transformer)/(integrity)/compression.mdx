## Overview [#overview]

`@unikvs/compression` is a Transformer plugin that transparently compresses and decompresses byte sequences. <Badge>Transformer</Badge>

Use it when you want to reduce storage size.

- It wraps the Web standard `CompressionStream` and `DecompressionStream` to fit `ITransformer`.
- The supported formats are `gzip`, `deflate`, and `deflate-raw`; choose `gzip` when you value compatibility.
- It is always open. No `open` or `close` is needed; `isOpen` always returns `true` and `name` always returns `"Compression"`.

:::warning
Use a single format per KVS. Data cannot be decompressed when the formats differ between compression and decompression.
:::

Install with the following command.

```package-install
npm install @unikvs/compression
```

## Usage [#usage]

`Compression` implements ITransformer. Pass it to UniKvs via transform().

```ts
import { Compression } from "@unikvs/compression";
```

The constructor arguments are as follows.

<TypeTable
  type={{
    format: {
      type: '"gzip" | "deflate" | "deflate-raw"',
      required: true,
      description: "The compression format. Round-trip with the same format for decompression.",
    },
  }}
/>

Below is an example of saving a written value compressed with gzip and decompressing it on read.

```ts
import { Compression } from "@unikvs/compression";
import { Memory } from "@unikvs/memory";
import UniKvs, { type PlainValue } from "unikvs";

const kvs = UniKvs.config<{ data: PlainValue<Uint8Array<ArrayBuffer>> }>()
  .connect(new Compression("gzip"))
  .persist(new Memory())
  .create();

await kvs.open();

const input = new TextEncoder().encode("Repeat this text. ".repeat(100));
await kvs.set("data", input);

const output = await kvs.get("data");

await kvs.close();
```

## Data Types [#data-types]

| Method         | Input                     | Output                             |
| -------------- | ------------------------- | ---------------------------------- |
| `encode`       | `Uint8Array<ArrayBuffer>` | `Promise<Uint8Array<ArrayBuffer>>` |
| `decode`       | `Uint8Array<ArrayBuffer>` | `Promise<Uint8Array<ArrayBuffer>>` |
| `getEncodable` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>`          |
| `getDecodable` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>`          |

- `encode` compresses a byte sequence.
- `decode` decompresses a compressed byte sequence.
- One-shot conversions are both asynchronous; call them with `await`.
- Repetitive text tends to shrink well, while already-compressed or random-like data tends to shrink poorly.
- Even when it does not shrink, decompressing restores the original.

- Chunks are simply concatenated with no delimiter.
- `getEncodable` returns the `CompressionStream` as is.
- `getDecodable` returns the `DecompressionStream` as is.
- Uneven multi-chunk data returns to the original bytes after a round trip.

## Errors [#errors]

This package has no package-specific errors. When you specify a format the runtime does not support, a native `TypeError` is thrown when constructing the `CompressionStream` or `DecompressionStream`. Passing uncompressed bytes to `decode` also fails to decompress. Use the same format for compression and decompression.
