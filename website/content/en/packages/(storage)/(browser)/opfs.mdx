## Overview [#overview]

<Badge variant="warning">Browser only</Badge>

`@unikvs/opfs` is a storage plugin that saves data in the browser's OPFS (Origin Private File System).

Use it to save bytes in a file area isolated per origin.

- `name` always returns `"Opfs"`. Open the working root with `open` before use. There is no `close`.
- Keys are stored one-to-one as file names directly under the specified root.
- A string root is normalized, and a passed handle is treated as already open.

:::warning
OPFS availability depends on the browser type, version, and settings. Check the browser documentation for supported conditions.
:::

Install with the following command.

```package-install
npm install @unikvs/opfs
```

## Usage [#usage]

`Opfs` implements IStorage. Pass it to UniKvs via persist().

```ts
import { Opfs } from "@unikvs/opfs";
```

The constructor arguments are as follows.

<TypeTable
  type={{
    root: {
      type: "string | FileSystemDirectoryHandle",
      default: '".unikvs"',
      description: "Root name in OPFS, or the handle of the working target.",
    },
    options: {
      type: "OpfsOptions",
      description: "Settings for repair-write permission. Uses defaults when omitted.",
    },
    "options.allowRepair": {
      type: "boolean",
      default: "false",
      description: "Whether to allow writes via repair.",
    },
  }}
/>

Below is an example of saving a value and reading it back.

```ts
import { Opfs } from "@unikvs/opfs";
import { UniKvs, type Value } from "unikvs";

const kvs = UniKvs.config<{
  data: Value<Uint8Array<ArrayBuffer>>;
}>()
  .persist(new Opfs(".unikvs"))
  .create();

await kvs.open();

await kvs.set("data", new TextEncoder().encode("hello"));
const data = await kvs.get("data");

await kvs.close();
```

## Data types [#data-types]

| Operation                           | Supported data type       |
| ----------------------------------- | ------------------------- |
| `write`・`read`                     | `Uint8Array<ArrayBuffer>` |
| `getWritable`・`getReadable` chunks | `Uint8Array<ArrayBuffer>` |

- `write` and `read` support bytes only.
- `write`, `read`, `exists`, `delete`, and `clear` are all asynchronous.
- Keys and root names have file-name constraints; invalid names fail validation.
- Stream operations only support `Uint8Array<ArrayBuffer>`.
- `getWritable` wraps a file write and finalizes it on `close`.
- `getReadable` relays the file contents.

## Errors [#errors]

This package has no package-specific errors. A write with repair disallowed fails with `RepairNotAllowedError` from `@unikvs/core`, and reading a missing key fails with a `NotFoundError` `DOMException`.
