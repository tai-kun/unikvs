## Overview [#overview]

<Badge variant="warning">Browser only</Badge>

`@unikvs/indexeddb` is a storage plugin that saves data in the browser's IndexedDB.

Use it to store arbitrary data keyed by name.

- `name` always returns `"Indexeddb"`. Connect with `open` before use and close with `close`.
- All reads and writes are asynchronous.
- Internal operations use `idb`.

Install with the following command.

```package-install
npm install @unikvs/indexeddb
```

## Usage [#usage]

`Indexeddb` implements IStorage. Pass it to UniKvs via persist().

```ts
import { Indexeddb } from "@unikvs/indexeddb";
```

The constructor arguments are as follows.

  type={{
    dbName: {
      type: "string",
      default: '"unikvs_db"',

    storeName: {
      type: "string",

    },

Below is an example of saving a value and reading it back.

```ts
import { Indexeddb } from "@unikvs/indexeddb";
import { UniKvs, type Value } from "unikvs";

const kvs = UniKvs.config<{
  greeting: Value<string>;
}>()
  .persist(new Indexeddb())
  .create();

await kvs.open();

await kvs.set("greeting", "hello");
const greeting = await kvs.get("greeting");

await kvs.close();
```

## Data types [#data-types]

| Operation                           | Supported data type                            |
| ----------------------------------- | ---------------------------------------------- |
| `write`・`read`                     | Arbitrary values (strings, objects, and so on) |
| `getWritable`・`getReadable` chunks | `Uint8Array<ArrayBuffer>`                      |

- `write` and `read` support arbitrary values such as strings and objects, and store them as-is.
- `write`, `read`, `exists`, `delete`, and `clear` are all asynchronous.
- Stream operations only support `Uint8Array<ArrayBuffer>`.
- `getWritable` buffers chunks in memory and saves them joined on `close`.
- `getReadable` emits the stored value as a single chunk.

## Errors [#errors]

This package has no package-specific errors. A write with repair disallowed fails with `RepairNotAllowedError` from `@unikvs/core`, and reading a missing key fails with a `NotFoundError` `DOMException`.
