## Overview [#overview]

<Badge variant="warning">Node.js only</Badge>

`@unikvs/fs.node` is a storage plugin that saves data in Node.js's local file system.

Use it to save keys as file names under a specified root directory.

- `name` always returns `"NodeFs"`. Create the root with `open` before use. There is no `close`.
- Relative paths are resolved against the current directory when `open` runs.
- Writes go to a temporary file first, then `rename` into place.

Install with the following command.

```package-install
npm install @unikvs/fs.node
```

## Usage [#usage]

`NodeFs` implements IStorage. Pass it to UniKvs via persist().

```ts
import { NodeFs } from "@unikvs/fs.node";
```

The constructor arguments are as follows.

<TypeTable
  type={{
    root: {
      type: "string",
      default: '".unikvs"',
      description: "Root directory for storage.",
    },
    options: {
      type: "NodeFsOptions",
      description: "Settings for repair-write permission. Uses defaults when omitted.",
    },
    "options.allowRepair": {
      type: "boolean",
      default: "false",
      description: "Whether to allow writes via repair.",
    },
  }}
/>

Below is an example of saving a value and reading it back.

```ts
import { NodeFs } from "@unikvs/fs.node";
import { UniKvs, type Value } from "unikvs";

const kvs = UniKvs.config<{
  data: Value<Uint8Array<ArrayBuffer>>;
}>()
  .persist(new NodeFs("./.tmp/unikvs-fs-node"))
  .create();

await kvs.open();

await kvs.set("data", new TextEncoder().encode("hello"));
const data = await kvs.get("data");

await kvs.close();
```

## Data types [#data-types]

| Operation | Supported data type |
| --- | --- |
| `write`・`read` | `Uint8Array<ArrayBuffer>` |
| `getWritable`・`getReadable` chunks | `Uint8Array<ArrayBuffer>` |

- `write` and `read` support bytes only.
- `write`, `read`, `exists`, `delete`, and `clear` are all asynchronous.
- Keys have file-name constraints; invalid keys fail validation.
- Stream operations only support `Uint8Array<ArrayBuffer>`.
- `getWritable` writes to a temporary file and replaces the final path when `close` succeeds.
- `getReadable` relays the file contents.

## Errors [#errors]

This package has no package-specific errors. A write with repair disallowed fails with `RepairNotAllowedError` from `@unikvs/core`, and reading or deleting a missing key fails with a native `ENOENT`.
