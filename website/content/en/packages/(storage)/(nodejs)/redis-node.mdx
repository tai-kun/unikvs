## Overview [#overview]

<Badge variant="warning">Node.js only</Badge>

`@unikvs/redis.node` is a storage plugin that saves data in Redis with `ioredis`.

Use it to separate namespaces by prefixing keys.

- `name` always returns `"Redis"`. Connect with `open` before use and close with `close`. Always `await` `close`.
- When `url` is omitted, it is resolved from `REDIS_URL` and then `VALKEY_URL`.
- Every key is stored with a `keyPrefix`. The default is `"unikvs:"`.

:::warning
With an empty `keyPrefix`, `clear` deletes every key in the selected database. Always specify a unique prefix for shared databases.
:::

Install with the following command.

```package-install
npm install @unikvs/redis.node
```

`ioredis` is installed automatically as a dependency. Prepare the Redis server separately.

## Usage [#usage]

`Redis` implements IStorage. Pass it to UniKvs via persist().

```ts
import { Redis } from "@unikvs/redis.node";
```

The constructor arguments are as follows.

<TypeTable
  type={{
    url: {
      type: "string",
      description: "Connection target. Resolved from environment variables when omitted.",
    },
    options: {
      type: "RedisStorageOptions",
      description: "Settings for the prefix and the client. Uses defaults when omitted.",
    },
    "options.keyPrefix": {
      type: "string",
      default: '"unikvs:"',
      description: "Prefix added to every key. Limits the deletion scope of `clear`.",
    },
    "options.allowRepair": {
      type: "boolean",
      default: "false",
      description: "Whether to allow writes via repair.",
    },
    "options.closeTimeout": {
      type: "number",
      default: "5000",
      description:
        "Cutoff limit in milliseconds for `close`. Accepts finite positive numbers only.",
    },
  }}
/>

Below is an example of saving a value and reading it back.

```ts
import { Redis } from "@unikvs/redis.node";
import { UniKvs, type Value } from "unikvs";

const kvs = UniKvs.config<{
  data: Value<Uint8Array<ArrayBuffer>>;
}>()
  .persist(new Redis("redis://localhost:6379", { keyPrefix: "myapp:" }))
  .create();

await kvs.open();

await kvs.set("data", new TextEncoder().encode("hello"));
const data = await kvs.get("data");

await kvs.close();
```

## Data types [#data-types]

| Operation                           | Supported data type       |
| ----------------------------------- | ------------------------- |
| `write`・`read`                     | `Uint8Array<ArrayBuffer>` |
| `getWritable`・`getReadable` chunks | `Uint8Array<ArrayBuffer>` |

- `write` and `read` support bytes only.
- `write`, `read`, `exists`, `delete`, and `clear` are all asynchronous.
- `delete` succeeds even for missing keys.
- Stream operations only support `Uint8Array<ArrayBuffer>`.
- `getWritable` appends to a temporary key and replaces the final key on `close`.
- `getReadable` emits the stored value as a single chunk.

## Errors [#errors]

This package throws the following errors.

### KeyNotFoundError

#### Meaning

The specified key does not exist. A shared error from `@unikvs/core`.

#### How to handle

Check with `exists` before reading, or verify the key spelling.

#### Example

Below is an example of catching `KeyNotFoundError`.

```ts
import { KeyNotFoundError, Redis } from "@unikvs/redis.node";

const storage = new Redis("redis://localhost:6379");

await storage.open();

try {
  await storage.read({ key: "missing.bin" });
} catch (error) {
  if (error instanceof KeyNotFoundError) {
    console.log(error.meta.key);
  } else {
    throw error;
  }
} finally {
  await storage.close();
}
```

### ClusterNotSupportedError

#### Meaning

Built with `cluster` specified. v1 only supports standalone connections.

#### How to handle

Recreate the instance without specifying `cluster`.

### InvalidCloseTimeoutError

#### Meaning

`closeTimeout` is not a finite positive number. Includes `actual` in `meta`.

#### How to handle

Specify a finite positive number, or omit it to use the default.

### ConnectTimeoutError

#### Meaning

The initial connection in `open` exceeded the cutoff limit. Includes `timeoutMs` in `meta`.

#### How to handle

Check the destination and network state, and review `connectTimeout` if needed.

### RepairNotAllowedError

#### Meaning

A write via repair (`repair`) is not allowed. Includes `name` in `meta`. A shared error from `@unikvs/core`.

#### How to handle

Recreate the instance with `allowRepair: true`, or avoid repair writes in your workflow.
