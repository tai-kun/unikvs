## Overview [#overview]

<Badge variant="warning">Bun only</Badge>

`@unikvs/redis.bun` is a storage plugin that saves data in Redis with Bun's built-in Redis client.

Use it to separate namespaces by prefixing keys.

- `name` always returns `"Redis"`. Connect with `open` before use and close with `close`.
- When `url` is omitted, it is resolved from `REDIS_URL` and then `VALKEY_URL`.
- Every key is stored with a `keyPrefix`. The default is `"unikvs:"`.

:::warning
With an empty `keyPrefix`, `clear` deletes every key in the selected database. Always specify a unique prefix for shared databases.
:::

Install with the following command.

```package-install
npm install @unikvs/redis.bun
```

Prepare the Redis server separately.

## Usage [#usage]

`Redis` implements IStorage. Pass it to UniKvs via persist().

```ts
import { Redis } from "@unikvs/redis.bun";
```

The constructor arguments are as follows.

<TypeTable
  type={{
    url: {
      type: "string",
      description: "Connection target. Resolved from environment variables when omitted.",
    },
    options: {
      type: "RedisStorageOptions",
      description: "Settings for the prefix and the client. Uses defaults when omitted.",
    },
    "options.keyPrefix": {
      type: "string",
      default: '"unikvs:"',
      description: "Prefix added to every key. Limits the deletion scope of `clear`.",
    },
    "options.allowRepair": {
      type: "boolean",
      default: "false",
      description: "Whether to allow writes via repair.",
    },
  }}
/>

Below is an example of saving a value and reading it back.

```ts
import { Redis } from "@unikvs/redis.bun";
import { UniKvs, type Value } from "unikvs";

const kvs = UniKvs.config<{
  data: Value<Uint8Array<ArrayBuffer>>;
}>()
  .persist(new Redis("redis://localhost:6379", { keyPrefix: "myapp:" }))
  .create();

await kvs.open();

await kvs.set("data", new TextEncoder().encode("hello"));
const data = await kvs.get("data");

await kvs.close();
```

## Data types [#data-types]

| Operation                           | Supported data type       |
| ----------------------------------- | ------------------------- |
| `write`・`read`                     | `Uint8Array<ArrayBuffer>` |
| `getWritable`・`getReadable` chunks | `Uint8Array<ArrayBuffer>` |

- `write` and `read` support bytes only.
- `write`, `read`, `exists`, `delete`, and `clear` are all asynchronous.
- `delete` succeeds even for missing keys.
- Stream operations only support `Uint8Array<ArrayBuffer>`.
- `getWritable` appends to a temporary key and replaces the final key on `close`.
- `getReadable` emits the stored value as a single chunk.

## Errors [#errors]

This package has no package-specific errors. Reading a missing key fails with `KeyNotFoundError` from `@unikvs/core`, and calling `open` outside Bun fails with `UnsupportedRuntimeError`.
