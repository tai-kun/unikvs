## Overview [#overview]

`@unikvs/utils` provides shared helpers for plugin authors. It collects commonly needed processing such as filename/dirname validation, byte conversion and splitting, and iterable-to-`ReadableStream` conversion.

<Badge>For plugin authors</Badge>

You can install it with the following command.

```package-install
npm install @unikvs/utils
```

Use it with named imports as follows.

```ts
import {
  assertValidFilename,
  assertValidDirname,
  bytesToHex,
  chunks,
  isValidFilename,
  isValidDirname,
  toReadableStream,
  withReadableStreamFrom,
  InvalidDirnameError,
  InvalidFilenameError,
} from "@unikvs/utils";
```

## Filename Validation [#filename]

Validates whether a filename works on Windows, macOS, and Linux.

### isValidFilename [#is-valid-filename]

```ts
function isValidFilename(filename: string): boolean;
```

Returns `false` if any of the following applies. It never throws.

- It is an empty string, `"."`, or `".."`.
- Its byte length after UTF-8 encoding exceeds 255 bytes.
- The result of decoding after encoding does not match the original string, for example because it contains a BOM.
- The result of NFC normalization does not match the original string.
- It contains control or reserved characters.
- It matches a Windows reserved name.
- It contains `":"`.

```ts
import { isValidFilename } from "@unikvs/utils";

if (isValidFilename("report.txt")) {
  console.log("Valid filename.");
}
```

### assertValidFilename [#assert-valid-filename]

```ts
function assertValidFilename(filename: string): void;
```

Returns silently for valid names, and throws `InvalidFilenameError` for invalid names.

```ts
import { assertValidFilename } from "@unikvs/utils";

assertValidFilename("report.txt");
```

:::tip
Use `isValidFilename` for a boolean check, and `assertValidFilename` to abort with a reason on invalid input.
:::

## Dirname Validation [#dirname]

Validates whether a dirname works on Windows, macOS, and Linux. It delegates to filename validation, so the conditions are the same.

### isValidDirname [#is-valid-dirname]

```ts
function isValidDirname(dirname: string): boolean;
```

Returns `true` for valid names and `false` for invalid ones. It never throws.

```ts
import { isValidDirname } from "@unikvs/utils";

if (!isValidDirname("my-dir")) {
  console.log("Invalid dirname.");
}
```

### assertValidDirname [#assert-valid-dirname]

```ts
function assertValidDirname(dirname: string): void;
```

Returns silently for valid names, and throws `InvalidDirnameError` for invalid names.

```ts
import { assertValidDirname } from "@unikvs/utils";

assertValidDirname("my-dir");
```

## Byte Operations [#bytes]

Converts and splits binary data.

### bytesToHex [#bytes-to-hex]

```ts
function bytesToHex(bytes: Uint8Array): string;
```

Converts a `Uint8Array` to a lowercase hex string. It uses `Uint8Array.prototype.toHex` where available, and a precomputed table otherwise. It never throws.

```ts
import { bytesToHex } from "@unikvs/utils";

const hex = bytesToHex(new Uint8Array([0, 255, 16]));
console.log(hex); // "00ff10"
```

### chunks [#chunks]

```ts
function chunks<TData extends DataView | ITypedArray>(
  data: TData,
  maxChunkByteSize: number,
): Generator<TData, void, unknown>;
```

Splits a `DataView` or TypedArray into chunks of at most `maxChunkByteSize` bytes, yielding them in order. `maxChunkByteSize` is truncated and treated as at least 1.

For a `DataView` it returns a new `DataView` sliced from the buffer range; for a TypedArray it returns a view via `subarray`. It does not copy the original data.

```ts
import { chunks } from "@unikvs/utils";

const data = new Uint8Array([1, 2, 3, 4, 5]);

for (const chunk of chunks(data, 2)) {
  console.log(chunk);
}
```

:::warning
The returned chunks are views into the original data. Writes to a chunk affect the original, so copy separately to keep it.
:::

## Stream Conversion [#streams]

Converts iterables into Web Streams `ReadableStream`.

### toReadableStream [#to-readable-stream]

```ts
function toReadableStream<T>(
  iterable: Iterable<T> | AsyncIterable<T>,
): ReadableStream<T>;
```

Creates a `ReadableStream` from a sync or async iterable. It uses a temporary polyfill where `ReadableStream.from` is missing.

```ts
import { toReadableStream } from "@unikvs/utils";

const stream = toReadableStream([1, 2, 3]);

for await (const value of stream) {
  console.log(value);
}
```

### withReadableStreamFrom [#with-readable-stream-from]

```ts
function withReadableStreamFrom<T>(
  cb: (ReadableStream: ReadableStreamWithFrom) => T,
): T;
```

Runs the callback as-is where `ReadableStream.from` exists; otherwise it temporarily defines `from`, runs the callback, and removes it. Keep the callback synchronous. Passing an async function is deprecated.

```ts
import { withReadableStreamFrom } from "@unikvs/utils";

const stream = withReadableStreamFrom((ReadableStream) =>
  ReadableStream.from([1, 2, 3]),
);
```

:::warning
Keep the callback synchronous. Async functions are deprecated.
:::

## Errors [#errors]

Filename and dirname validation errors.

### InvalidFilenameError [#invalid-filename-error]

Thrown for an unusable filename. Its `name` is `"UniKvsInvalidFilenameError"`, holding the invalid `filename` as metadata.

```ts
import { InvalidFilenameError } from "@unikvs/utils";

throw new InvalidFilenameError({ filename: "../evil" });
```

<Accordion>
  <AccordionItem title="Constructor arguments and message">
The argument type is `InvalidFilenameErrorArgs`, combining `ErrorOptions` and metadata. The message is ``Invalid file name: ...`` in English and ``無効なファイル名: ...`` in Japanese.
  </AccordionItem>
</Accordion>

### InvalidDirnameError [#invalid-dirname-error]

Thrown for an unusable dirname. Its `name` is `"UniKvsInvalidDirnameError"`, holding the invalid `dirname` as metadata.

```ts
import { InvalidDirnameError } from "@unikvs/utils";

throw new InvalidDirnameError({ dirname: ".." });
```

<Accordion>
  <AccordionItem title="Constructor arguments and message">
The argument type is `InvalidDirnameErrorArgs`, combining `ErrorOptions` and metadata. The message is ``Invalid directory name: ...`` in English and ``無効なディレクトリー名: ...`` in Japanese.
  </AccordionItem>
</Accordion>

## Examples [#examples]

An example combining filename validation, binary splitting, and stream conversion.

```ts
import {
  assertValidFilename,
  chunks,
  InvalidFilenameError,
  toReadableStream,
} from "@unikvs/utils";

async function saveChunks(filename: string, data: Uint8Array): Promise<void> {
  try {
    assertValidFilename(filename);
  } catch (error) {
    if (error instanceof InvalidFilenameError) {
      console.error(`Invalid filename: ${error.meta.filename}`);
    }
    throw error;
  }

  const stream = toReadableStream(chunks(data, 64 * 1024));

  for await (const chunk of stream) {
    await writeChunk(filename, chunk);
  }
}

async function writeChunk(filename: string, chunk: Uint8Array): Promise<void> {
  console.log(`${filename}: writing ${chunk.byteLength} bytes.`);
}
```
