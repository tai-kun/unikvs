## Overview [#overview]

<Badge variant="warning">Browser only</Badge>

`@unikvs/indexeddb` is a storage plugin that uses the browser's IndexedDB as its persistence layer. It stores arbitrary data keyed by name.

Internal IndexedDB operations use the `idb` package (`8.0.3`). It implements `IStorage` from `@unikvs/core`.

Install it as follows.

```package-install
npm install @unikvs/indexeddb
```

## Usage [#usage]

The storage class is named `Indexeddb` and is provided as a default export. Its `name` property is `"Indexeddb"`.

```ts
import Indexeddb from "@unikvs/indexeddb";
```

The constructor arguments are as follows. Both are optional.

| Argument | Type | Default | Description |
| ---- | -- | ------ | ---- |
| `dbName` | `string` | `"unikvs_db"` | The database name to use. |
| `storeName` | `string` | `"kvs_store"` | The object store name where data is saved. |

```ts
import Indexeddb from "@unikvs/indexeddb";

// Using the defaults (unikvs_db / kvs_store)
const storage = new Indexeddb();

// Specifying the database and store names
const customStorage = new Indexeddb("my-app-db", "my-store");
```

<Expandable title="Defaults and open behavior">
When `dbName` is omitted, `"unikvs_db"` is used; when `storeName` is omitted, `"kvs_store"` is used. Call `open()` before use. `open()` connects with database version `1` and creates the store when missing. It does nothing when already open. Check the open state with `isOpen` and close the connection with `close()`.
</Expandable>

Registering with `UniKvs` looks like this.

```ts
import Indexeddb from "@unikvs/indexeddb";
import { UniKvs } from "unikvs";

const kvs = UniKvs.config()
  .appendStorage(new Indexeddb())
  .create();

await kvs.open();
await kvs.set("greeting", "hello");
const value = await kvs.get("greeting");
await kvs.close();
```

## Data Format [#data]

`write` accepts data of type `any`, and `read` returns data of type `any`. Passed values are forwarded to `idb`'s `put` as-is, and `get` results are returned as-is. Byte sequences and other values alike can therefore be stored.

:::note
`write` accepts data of type `any`, and passed values are forwarded to `idb`'s `put` as-is. `get` results are returned as-is on retrieval. Byte sequences and other values alike can therefore be stored.
:::

Streams are also supported. However, IndexedDB has no native streaming, so they are emulated in memory as follows.

- `getWritable` returns a `WritableStream<Uint8Array>`. Written chunks are buffered in memory and concatenated into a single `Uint8Array` when the stream closes.
- `getReadable` returns a `ReadableStream<Uint8Array>`. The entire value is loaded into memory, then emitted as a single chunk before closing the stream.

:::warning
`getWritable` and `getReadable` hold the entire value in memory. Watch memory usage when handling large data.
:::

Existence checks use the `count()` result, deletion uses `delete()`, and full clearing uses `clear()`.

## Notes [#notes]

- All read/write methods are asynchronous. Do not call `write`, `read`, `exists`, `delete`, or `clear` before `open()` completes. The internal database connection is `null` until `open()` finishes.
- `read` throws a `DOMException` (`NotFoundError`) for a missing key. This matches the behavior of the Opfs plugin. Check beforehand with `exists()`.
- `getWritable` and `getReadable` hold the entire value in memory. Watch memory usage when handling large data.
- The database version is fixed at `1`, and the store is created automatically when missing. No logic for migrating an existing database structure is included.
- Browser only. It uses IndexedDB, `DOMException`, `WritableStream`, and `ReadableStream`. Development dependencies include packages for browser testing.
- Available capacity and quota handling depend on the browser. Data may not persist in private mode and similar contexts.

## Examples [#examples]

A minimal browser example is shown below.

<Steps>
  <Step title="Open the storage">
    Create an `Indexeddb` with the defaults (unikvs_db / kvs_store) and connect with `open()`.

    ```ts
    import Indexeddb from "@unikvs/indexeddb";

    const storage = new Indexeddb();

    await storage.open();
    ```
  </Step>
  <Step title="Write data">
    Save arbitrary data under a key with `write`.

    ```ts
    await storage.write({ key: "greeting", data: "hello" });
    ```
  </Step>
  <Step title="Read data">
    Check with `exists`, then retrieve with `read`.

    ```ts
    if (await storage.exists({ key: "greeting" })) {
      const value = await storage.read({ key: "greeting" });
      console.log(value);
    }
    ```
  </Step>
  <Step title="Delete data and close">
    Delete with `delete` and close the connection with `close()`.

    ```ts
    await storage.delete({ key: "greeting" });
    await storage.close();
    ```
  </Step>
</Steps>
