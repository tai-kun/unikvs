## 概要 [#overview]

`@unikvs/utils` は、プラグイン実装者向けの共有関数群を提供するパッケージです。ファイル名やディレクトリ名の検証、バイト列の変換や分割、反復可能オブジェクトから `ReadableStream` への変換など、各プラグインで共通に必要になる処理をまとめています。

<Badge>プラグイン実装者向け</Badge>

次のコマンドでインストールできます。

```package-install
npm install @unikvs/utils
```

次のように名前付きインポートで利用します。

```ts
import {
  assertValidFilename,
  assertValidDirname,
  bytesToHex,
  chunks,
  isValidFilename,
  isValidDirname,
  toReadableStream,
  withReadableStreamFrom,
  InvalidDirnameError,
  InvalidFilenameError,
} from "@unikvs/utils";
```

## ファイル名の検証 [#filename]

Windows・macOS・Linux で使えるファイル名か検証します。

### isValidFilename [#is-valid-filename]

```ts
function isValidFilename(filename: string): boolean;
```

次のいずれかに当てはまると `false` を返します。例外は投げません。

- 空文字列、`"."`、`".."` である場合
- UTF-8 エンコード後のバイト数が 255 バイトを超える場合
- BOM を含むなど、エンコード後にデコードした結果が元の文字列と一致しない場合
- NFC 正規化した結果が元の文字列と一致しない場合
- 制御文字や予約文字を含む場合
- Windows の予約名に一致する場合
- `":"` を含む場合

```ts
import { isValidFilename } from "@unikvs/utils";

if (isValidFilename("report.txt")) {
  console.log("利用可能なファイル名です。");
}
```

### assertValidFilename [#assert-valid-filename]

```ts
function assertValidFilename(filename: string): void;
```

有効なら何もせずに戻り、無効なら `InvalidFilenameError` を投げます。

```ts
import { assertValidFilename } from "@unikvs/utils";

assertValidFilename("report.txt");
```

:::tip
真偽値で判定するなら `isValidFilename` を、無効時に理由付きで止めるなら `assertValidFilename` を使います。
:::

## ディレクトリ名の検証 [#dirname]

Windows・macOS・Linux で使えるディレクトリ名か検証します。内部でファイル名の検証に委譲するため、判定条件は同じです。

### isValidDirname [#is-valid-dirname]

```ts
function isValidDirname(dirname: string): boolean;
```

有効なら `true` を、無効なら `false` を返します。例外は投げません。

```ts
import { isValidDirname } from "@unikvs/utils";

if (!isValidDirname("my-dir")) {
  console.log("利用できないディレクトリ名です。");
}
```

### assertValidDirname [#assert-valid-dirname]

```ts
function assertValidDirname(dirname: string): void;
```

有効なら何もせずに戻り、無効なら `InvalidDirnameError` を投げます。

```ts
import { assertValidDirname } from "@unikvs/utils";

assertValidDirname("my-dir");
```

## バイト列操作 [#bytes]

バイナリーデータの変換と分割を行います。

### bytesToHex [#bytes-to-hex]

```ts
function bytesToHex(bytes: Uint8Array): string;
```

`Uint8Array` を小文字の 16 進数文字列に変換します。`Uint8Array.prototype.toHex` があれば使い、なければ事前計算テーブルで変換します。例外は投げません。

```ts
import { bytesToHex } from "@unikvs/utils";

const hex = bytesToHex(new Uint8Array([0, 255, 16]));
console.log(hex); // "00ff10"
```

### chunks [#chunks]

```ts
function chunks<TData extends DataView | ITypedArray>(
  data: TData,
  maxChunkByteSize: number,
): Generator<TData, void, unknown>;
```

`DataView` または TypedArray を、1 チャンクあたり最大 `maxChunkByteSize` バイトになるように分割し、チャンクを順に生成するジェネレーターを返します。`maxChunkByteSize` は小数点以下を切り捨て、最低でも 1 として扱います。

`DataView` の場合はバッファー範囲で切り出した新しい `DataView` を、TypedArray の場合は `subarray` によるビューを返します。元のデータはコピーしません。

```ts
import { chunks } from "@unikvs/utils";

const data = new Uint8Array([1, 2, 3, 4, 5]);

for (const chunk of chunks(data, 2)) {
  console.log(chunk);
}
```

:::warning
返すチャンクは元のデータへのビューです。書き込むと元データに反映されるため、保持したい場合は別途コピーしてください。
:::

## ストリーム変換 [#streams]

反復可能オブジェクトを Web Streams の `ReadableStream` に変換します。

### toReadableStream [#to-readable-stream]

```ts
function toReadableStream<T>(
  iterable: Iterable<T> | AsyncIterable<T>,
): ReadableStream<T>;
```

同期・非同期の反復可能オブジェクトから `ReadableStream` を作ります。`ReadableStream.from` がない環境では一時的なポリフィルを使います。

```ts
import { toReadableStream } from "@unikvs/utils";

const stream = toReadableStream([1, 2, 3]);

for await (const value of stream) {
  console.log(value);
}
```

### withReadableStreamFrom [#with-readable-stream-from]

```ts
function withReadableStreamFrom<T>(
  cb: (ReadableStream: ReadableStreamWithFrom) => T,
): T;
```

`ReadableStream.from` がある環境ではそのまま実行し、ない環境では一時的に `from` を定義して実行後に削除します。コールバックは同期関数にしてください。非同期関数を渡す使い方は非推奨です。

```ts
import { withReadableStreamFrom } from "@unikvs/utils";

const stream = withReadableStreamFrom((ReadableStream) =>
  ReadableStream.from([1, 2, 3]),
);
```

:::warning
コールバックは同期関数にしてください。非同期関数は非推奨です。
:::

## エラー [#errors]

ファイル名・ディレクトリ名の検証エラーです。

### InvalidFilenameError [#invalid-filename-error]

使えないファイル名を指定すると投げられます。`name` は `"UniKvsInvalidFilenameError"` で、無効だった `filename` をメタデータに保持します。

```ts
import { InvalidFilenameError } from "@unikvs/utils";

throw new InvalidFilenameError({ filename: "../evil" });
```

<Accordion>
  <AccordionItem title="コンストラクター引数とメッセージ">
    引数は `ErrorOptions` とメタデータ型を合わせた `InvalidFilenameErrorArgs` です。メッセージは英語で ``Invalid file name: ...``、日本語で ``無効なファイル名: ...`` になります。
  </AccordionItem>
</Accordion>

### InvalidDirnameError [#invalid-dirname-error]

使えないディレクトリ名を指定すると投げられます。`name` は `"UniKvsInvalidDirnameError"` で、無効だった `dirname` をメタデータに保持します。

```ts
import { InvalidDirnameError } from "@unikvs/utils";

throw new InvalidDirnameError({ dirname: ".." });
```

<Accordion>
  <AccordionItem title="コンストラクター引数とメッセージ">
    引数は `ErrorOptions` とメタデータ型を合わせた `InvalidDirnameErrorArgs` です。メッセージは英語で ``Invalid directory name: ...``、日本語で ``無効なディレクトリー名: ...`` になります。
  </AccordionItem>
</Accordion>

## 使用例 [#examples]

ファイル名の検証・バイナリーの分割・ストリーム変換を組み合わせる例です。

```ts
import {
  assertValidFilename,
  chunks,
  InvalidFilenameError,
  toReadableStream,
} from "@unikvs/utils";

async function saveChunks(filename: string, data: Uint8Array): Promise<void> {
  try {
    assertValidFilename(filename);
  } catch (error) {
    if (error instanceof InvalidFilenameError) {
      console.error(`無効なファイル名です: ${error.meta.filename}`);
    }
    throw error;
  }

  const stream = toReadableStream(chunks(data, 64 * 1024));

  for await (const chunk of stream) {
    await writeChunk(filename, chunk);
  }
}

async function writeChunk(filename: string, chunk: Uint8Array): Promise<void> {
  console.log(`${filename}: ${chunk.byteLength} バイトを書き込みます。`);
}
```
