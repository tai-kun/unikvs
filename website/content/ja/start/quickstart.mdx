メモリーストレージを使って、設定して作成し、開いて操作し、閉じるまでの一連の流れを試します。

<Steps>
  <Step title="ビルダーを作る">
    `UniKvs.config()` でビルダーを作ります。型パラメーターにキーと値のマッピングを指定します。

    ```ts
    import { UniKvs, type Value } from "unikvs";

    const builder = UniKvs.config<{
      foo: Value<Uint8Array>;
    }>();
    ```

  </Step>
  <Step title="保存先を追加して作る">
    `persist()` で保存先を追加し、`create()` でクライアントを作ります。トランスフォーマーが不要なら省略できます。

    ```ts
    import { Memory } from "@unikvs/memory";

    const kvs = builder.persist(new Memory()).create();
    ```

  </Step>
  <Step title="開いて操作する">
    `open()` で初期化し、`set`・`get`・`has`・`delete` などを操作します。

    ```ts
    await kvs.open();

    await kvs.set("foo", Uint8Array.from([0, 1, 2]));

    const bytes = await kvs.get("foo");
    console.log(bytes);

    console.log(await kvs.has("foo"));

    await kvs.delete("foo");
    ```

  </Step>
  <Step title="閉じる">
    使い終わったら `close()` で終了します。

    ```ts
    await kvs.close();
    ```

  </Step>
</Steps>

## コードの全文 [#full-code]

```ts
import { Memory } from "@unikvs/memory";
import { UniKvs, type Value } from "unikvs";

const kvs = UniKvs.config<{
  foo: Value<Uint8Array>;
}>()
  .persist(new Memory())
  .create();

await kvs.open();

await kvs.set("foo", Uint8Array.from([0, 1, 2]));

const bytes = await kvs.get("foo");
console.log(bytes); // Uint8Array(3) [0, 1, 2]

console.log(await kvs.has("foo")); // true

await kvs.delete("foo");
await kvs.close();
```

## ファイルに保存する [#persist-to-file]

`persist()` の引数を替えるだけで、保存先をファイルに変えられます。`open()` から `close()` までの操作は変わりません。

```ts
import { NodeFs } from "@unikvs/fs.node";

const kvs = UniKvs.config<{
  foo: Value<Uint8Array>;
}>()
  .persist(new NodeFs(".tmp"))
  .create();
```

この例では `.tmp/` 配下に保存します。パッケージの詳細は各[パッケージリファレンス](/packages)を参照してください。

:::warning[ストレージ登録は必須]
`persist()` なしで `create()` すると `MissingStorageError` を投げます。ストレージは少なくとも 1 つ登録してください。
:::
