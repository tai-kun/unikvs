## 概要 [#overview]

<Badge variant="warning">Node.js 専用</Badge>

`@unikvs/fs.node` は、Node.js のローカルファイルシステムに保存するストレージプラグインです。

指定したルートディレクトリー配下にキーをファイル名として保存する場合に使います。

- `name` は常に `"NodeFs"` を返します。使う前に `open` でルートを作ります。`close` はありません。
- 相対パスは `open` の実行時にカレントディレクトリー基準で解決します。
- 書き込みは一時ファイルへの書き出し後に `rename` します。

インストールは次のコマンドで行います。

```package-install
npm install @unikvs/fs.node
```

## 使い方 [#usage]

NodeFs は IStorage を実装しています。UniKvs には persist() で渡します。

```ts
import { NodeFs } from "@unikvs/fs.node";
```

コンストラクターの引数は次のとおりです。

<TypeTable
  type={{

    },

以下は、値を保存して読み戻す例です。

```ts
import { NodeFs } from "@unikvs/fs.node";
import { UniKvs, type Value } from "unikvs";

const kvs = UniKvs.config<{
  data: Value<Uint8Array<ArrayBuffer>>;
}>()
  .persist(new NodeFs("./.tmp/unikvs-fs-node"))
  .create();

await kvs.open();

await kvs.set("data", new TextEncoder().encode("hello"));
const data = await kvs.get("data");

await kvs.close();
```

## データ型 [#data-types]

| 操作 | 対応するデータ型 |
| --- | --- |
| `write`・`read` | `Uint8Array<ArrayBuffer>` |
| `getWritable`・`getReadable` のチャンク | `Uint8Array<ArrayBuffer>` |

- `write`・`read` はバイト列だけに対応しています。
- `write`・`read`・`exists`・`delete`・`clear` はいずれも非同期です。
- キーにはファイル名の制約があり、無効なキーは検証エラーになります。
- ストリーム操作は `Uint8Array<ArrayBuffer>` だけに対応しています。
- `getWritable` は一時ファイルへ書き出し、`close` 成功時に最終パスへ置き換えます。
- `getReadable` はファイルの内容を中継します。

## エラー [#errors]

このパッケージ固有のエラーはありません。書き戻しが禁止された状態での書き込みは `@unikvs/core` の `RepairNotAllowedError` で失敗し、存在しないキーの読み取りや削除はネイティブの `ENOENT` で失敗します。
