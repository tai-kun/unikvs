## 概要 [#overview]

<Badge variant="warning">Node.js 専用</Badge>

`@unikvs/redis.node` は、`ioredis` で Redis に保存するストレージプラグインです。

キーに接頭辞を付けて名前空間を分ける場合に使います。

- `name` は常に `"Redis"` を返します。使う前に `open` で接続し、`close` で閉じます。`close` は必ず `await` してください。
- `url` を省略すると `REDIS_URL`・`VALKEY_URL` の順に解決します。
- すべてのキーに `keyPrefix` を付けて保存します。既定値は `"unikvs:"` です。

:::warning
`keyPrefix` を空文字にすると、`clear` は選択中のデータベースの全キーを削除します。共有データベースでは必ず一意な接頭辞を指定してください。
:::

インストールは次のコマンドで行います。

```package-install
npm install @unikvs/redis.node
```

`ioredis` は依存関係として自動で導入されます。Redis サーバーは別途用意してください。

## 使い方 [#usage]

Redis は IStorage を実装しています。UniKvs には persist() で渡します。

```ts
import { Redis } from "@unikvs/redis.node";
```

コンストラクターの引数は次のとおりです。

以下は、値を保存して読み戻す例です。

```ts
import { Redis } from "@unikvs/redis.node";
import { UniKvs, type Value } from "unikvs";

const kvs = UniKvs.config<{
  data: Value<Uint8Array<ArrayBuffer>>;
}>()
  .persist(new Redis("redis://localhost:6379", { keyPrefix: "myapp:" }))
  .create();

await kvs.open();

await kvs.set("data", new TextEncoder().encode("hello"));
const data = await kvs.get("data");

await kvs.close();
```

## データ型 [#data-types]

| 操作                                    | 対応するデータ型          |
| --------------------------------------- | ------------------------- |
| `write`・`read`                         | `Uint8Array<ArrayBuffer>` |
| `getWritable`・`getReadable` のチャンク | `Uint8Array<ArrayBuffer>` |

- `write`・`read` はバイト列だけに対応しています。
- `write`・`read`・`exists`・`delete`・`clear` はいずれも非同期です。
- `delete` は存在しないキーでも成功します。
- ストリーム操作は `Uint8Array<ArrayBuffer>` だけに対応しています。
- `getWritable` は一時キーへ追記し、`close` 時に最終キーへ置き換えます。
- `getReadable` は保存値を単一チャンクとして送出します。

## エラー [#errors]

このパッケージが投げるエラーは次のとおりです。

### KeyNotFoundError

#### 意味

指定したキーが存在しません。`@unikvs/core` の共通エラーです。

#### 対処方法

`exists` で確認してから読み出すか、キーの指定誤りを確認してください。

#### 例

以下は、`KeyNotFoundError` を捕捉する例です。

```ts
import { KeyNotFoundError, Redis } from "@unikvs/redis.node";

const storage = new Redis("redis://localhost:6379");

await storage.open();

try {
  await storage.read({ key: "missing.bin" });
} catch (error) {
  if (error instanceof KeyNotFoundError) {
    console.log(error.meta.key);
  } else {
    throw error;
  }
} finally {
  await storage.close();
}
```

### ClusterNotSupportedError

#### 意味

`cluster` を指定して構築しました。v1 は単体接続だけに対応しています。

#### 対処方法

`cluster` を指定せずに生成し直してください。

### InvalidCloseTimeoutError

#### 意味

`closeTimeout` が有限の正数ではありません。`meta` に `actual` を含みます。

#### 対処方法

有限の正数を指定するか、省略して既定値を使ってください。

### ConnectTimeoutError

#### 意味

`open` の初回接続が打ち切り上限を超えました。`meta` に `timeoutMs` を含みます。

#### 対処方法

接続先とネットワークの状態を確認し、必要なら `connectTimeout` を見直してください。
