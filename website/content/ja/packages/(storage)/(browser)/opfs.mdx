## 概要 [#overview]

<Badge variant="warning">ブラウザー専用</Badge>

`@unikvs/opfs` は、ブラウザーの OPFS（Origin Private File System）に保存するストレージプラグインです。

オリジンごとに隔離されたファイル領域にバイト列を保存する場合に使います。

- `name` は常に `"Opfs"` を返します。使う前に `open` で作業対象を開きます。`close` はありません。
- キーはファイル名として、指定ルートの直下に 1 対 1 で保存します。
- 文字列のルートは正規化し、ハンドルを渡すとオープン済みとして扱います。

:::warning
OPFS の利用可否はブラウザーの種類・バージョン・設定に依存します。対応条件はブラウザーのドキュメントで確認してください。
:::

インストールは次のコマンドで行います。

```package-install
npm install @unikvs/opfs
```

## 使い方 [#usage]

Opfs は IStorage を実装しています。UniKvs には persist() で渡します。

```ts
import { Opfs } from "@unikvs/opfs";
```

コンストラクターの引数は次のとおりです。

<TypeTable
  type={{
    root: {
      type: "string | FileSystemDirectoryHandle",
      default: '".unikvs"',
      description: "OPFS 内のルート名か、作業対象のハンドルです。",
    },
  }}
/>

以下は、値を保存して読み戻す例です。

```ts
import { Opfs } from "@unikvs/opfs";
import { UniKvs, type Value } from "unikvs";

const kvs = UniKvs.config<{
  data: Value<Uint8Array<ArrayBuffer>>;
}>()
  .persist(new Opfs(".unikvs"))
  .create();

await kvs.open();

await kvs.set("data", new TextEncoder().encode("hello"));
const data = await kvs.get("data");

await kvs.close();
```

## データ型 [#data-types]

| 操作 | 対応するデータ型 |
| --- | --- |
| `write`・`read` | `Uint8Array<ArrayBuffer>` |
| `getWritable`・`getReadable` のチャンク | `Uint8Array<ArrayBuffer>` |

- `write`・`read` はバイト列だけに対応しています。
- `write`・`read`・`exists`・`delete`・`clear` はいずれも非同期です。
- キーとルート名にはファイル名の制約があり、無効な名前は検証エラーになります。
- ストリーム操作は `Uint8Array<ArrayBuffer>` だけに対応しています。
- `getWritable` はファイルへの書き込みを包み、`close` で確定します。
- `getReadable` はファイルの内容を中継します。

## エラー [#errors]

このパッケージ固有のエラーはありません。存在しないキーの読み取りは `NotFoundError` の `DOMException` で失敗します。
