## 概要 [#overview]

<Badge variant="warning">ブラウザー専用</Badge>

`@unikvs/indexeddb` は、ブラウザーの IndexedDB に保存するストレージプラグインです。

任意のデータをキーとひも付けて保存する場合に使います。

- `name` は常に `"Indexeddb"` を返します。使う前に `open` で接続し、`close` で閉じます。
- 読み書きはすべて非同期です。
- 内部操作には `idb` を使います。

インストールは次のコマンドで行います。

```package-install
npm install @unikvs/indexeddb
```

## 使い方 [#usage]

Indexeddb は IStorage を実装しています。UniKvs には persist() で渡します。

```ts
import { Indexeddb } from "@unikvs/indexeddb";
```

コンストラクターの引数は次のとおりです。

<TypeTable
  type={{
    dbName: {
      type: "string",
      default: '"unikvs_db"',
      description: "使用するデータベース名です。",
    },
    storeName: {
      type: "string",
      default: '"kvs_store"',
      description: "使用するオブジェクトストア名です。",
    },
  }}
/>

以下は、値を保存して読み戻す例です。

```ts
import { Indexeddb } from "@unikvs/indexeddb";
import { UniKvs, type Value } from "unikvs";

const kvs = UniKvs.config<{
  greeting: Value<string>;
}>()
  .persist(new Indexeddb())
  .create();

await kvs.open();

await kvs.set("greeting", "hello");
const greeting = await kvs.get("greeting");

await kvs.close();
```

## データ型 [#data-types]

| 操作 | 対応するデータ型 |
| --- | --- |
| `write`・`read` | 任意の値（文字列・オブジェクトなど） |
| `getWritable`・`getReadable` のチャンク | `Uint8Array<ArrayBuffer>` |

- `write`・`read` は文字列・オブジェクトなど任意の値に対応し、そのまま保存できます。
- `write`・`read`・`exists`・`delete`・`clear` はいずれも非同期です。
- ストリーム操作は `Uint8Array<ArrayBuffer>` だけに対応しています。
- `getWritable` はチャンクをメモリーにため、`close` 時に結合して保存します。
- `getReadable` は保存値を単一チャンクとして送出します。

## エラー [#errors]

このパッケージ固有のエラーはありません。存在しないキーの読み取りは `NotFoundError` の `DOMException` で失敗します。
