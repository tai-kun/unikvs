## 概要 [#overview]

`@unikvs/base64url` は、バイト列を URL 安全な base64（base64url）として表すバイト列へ変換する Transformer プラグインです。<Badge>Transformer</Badge>

URL やファイル名に埋め込む値、テキストしか保存できない保存先への格納に使います。

- 使用する 64 文字は RFC 4648 §5 の `A-Z`・`a-z`・`0-9`・`-`・`_` です。
- 常にオープン状態です。`open`・`close` は不要で、`isOpen` は常に `true`、`name` は常に `"Base64Url"` を返します。
- Node.js・Bun・ブラウザーで動作し、実行環境による振る舞いの違いはありません。

:::tip
小さく保存したい場合は [`@unikvs/compression`](/packages/compression) を、破損や改ざんを検知したい場合は [`@unikvs/checksum`](/packages/checksum) を検討してください。このパッケージに圧縮や検証の機能はありません。
:::

インストールは次のコマンドで行います。

```package-install
npm install @unikvs/base64url
```

## 使い方 [#usage]

Base64Url は ITransformer を実装しています。UniKvs には transform() で渡します。

```ts
import { Base64Url } from "@unikvs/base64url";
```

コンストラクターの引数は次のとおりです。

<TypeTable
  type={{
    options: {
      type: "Base64UrlOptions",
      description: "エンコードとパディングの設定です。省略時は既定値で動作します。",

    "options.encoder": {
      type: "FastUtf8",
      description: "base64url テキストをバイト列へ変換するエンコーダーです。差し替えが必要な場合にだけ指定します。",
    },
    "options.decoder": {

      description: "バイト列を base64url テキストへ変換するデコーダーです。差し替えが必要な場合にだけ指定します。",
    },
    "options.padding": {
      type: "boolean",
      default: "false",
      description: "末尾に `=` を付けて出力するかどうかです。`decode` は有無にかかわらず受け付けます。",
    },

/>

以下は、書き込んだ値を base64url 化して保存し、読み取り時に元のバイト列へ戻す例です。

```ts
import { Base64Url } from "@unikvs/base64url";
import { Memory } from "@unikvs/memory";
import UniKvs, { type PlainValue } from "unikvs";

const kvs = UniKvs.config<{ data: PlainValue<Uint8Array<ArrayBuffer>> }>()
  .transform(new Base64Url())
  .persist(new Memory())
  .create();

await kvs.open();

const input = new TextEncoder().encode("foobar");
await kvs.set("data", input);

const output = await kvs.get("data");

await kvs.close();
```

## データ型 [#data-types]

| メソッド | 入力 | 出力 |
| --- | --- | --- |
| `encode` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |
| `decode` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |
| `getEncodable` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |
| `getDecodable` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |

- `encode` はバイト列を RFC 4648 §5 の base64url テキストとして表すバイト列（UTF-8）へ変換します。
- `decode` は base64url テキストとして表すバイト列を元のバイト列に戻します。
- 変換後のサイズは元のサイズの約 1.37 倍になります。
- 既定では末尾の `=` を付けず、`padding: true` では `=` で埋めた正準形を出力します。
- 空入力は空出力です。

- チャンクは区切り文字なしで単純に結合されます。
- `getEncodable` は 3 バイト単位で区切って変換し、チャンク境界をまたいだ余り（1〜2 バイト）は内部に保持して次のチャンクと結合します。
- 末尾の `=` の有無はストリーム終了時に確定します。
- `getDecodable` は 4 文字単位で区切って復元し、未完成の文字は内部に保持して次のチャンクと結合します。
- 空のストリームと長さ 0 のチャンクは値を 1 つも生成しません。

## エラー [#errors]

このパッケージが投げるエラーは次のとおりです。

### Base64UrlDecodeError

#### 意味

入力を base64url として解釈できません。`+`・`/` や空白の混入、`=` の位置の誤り、4 で割って 1 余る長さが原因です。

#### 対処方法

入力が base64url（`A-Z`・`a-z`・`0-9`・`-`・`_` と末尾の `=`）の連続か確認してください。標準の base64 が必要な場合は呼び出し側で変換するか、`@unikvs/base64` を使ってください。

#### 例

以下は、`Base64UrlDecodeError` を捕捉する例です。

```ts
import { Base64Url, Base64UrlDecodeError } from "@unikvs/base64url";

const base64url = new Base64Url();

try {
  base64url.decode({ data: new TextEncoder().encode("ab+c") });
} catch (error) {
  if (error instanceof Base64UrlDecodeError) {
    console.log("base64url として解釈できません。");
  } else {
    throw error;
  }
}
```

UTF-8 として不正なバイト列は `Base64UrlDecodeError` ではなくネイティブの `TypeError` として伝わります。
