## 概要 [#overview]

`@unikvs/hex` は、バイト列を 16 進文字列（hex）として表すバイト列へ変換する Transformer プラグインです。<Badge>Transformer</Badge>

ハッシュ値やバイナリー内容の確認、デバッグ出力、テキストしか保存できない保存先への格納に使います。

- 出力は常に小文字（`0-9`・`a-f`）で、入力は大文字・小文字のどちらも受け付けます。
- 常にオープン状態です。`open`・`close` は不要で、`isOpen` は常に `true`、`name` は常に `"Hex"` を返します。
- Node.js・Bun・ブラウザーで動作し、実行環境による振る舞いの違いはありません。

:::tip
小さく保存したい場合は [`@unikvs/compression`](/packages/compression) を、破損や改ざんを検知したい場合は [`@unikvs/checksum`](/packages/checksum) を検討してください。このパッケージに圧縮や検証の機能はありません。
:::

インストールは次のコマンドで行います。

```package-install
npm install @unikvs/hex
```

## 使い方 [#usage]

Hex は ITransformer を実装しています。UniKvs には transform() で渡します。

```ts
import { Hex } from "@unikvs/hex";
```

コンストラクターの引数は次のとおりです。

<TypeTable
  type={{
    options: {
      type: "HexOptions",
      description: "UTF-8 変換の設定です。省略時は既定値で動作します。",
    },
    "options.encoder": {
      type: "FastUtf8",
      description:
        "hex テキストをバイト列へ変換するエンコーダーです。差し替えが必要な場合にだけ指定します。",
    },
    "options.decoder": {
      type: "FastUtf8",
      description:
        "バイト列を hex テキストへ変換するデコーダーです。差し替えが必要な場合にだけ指定します。",
    },
  }}
/>

以下は、書き込んだ値を hex 化して保存し、読み取り時に元のバイト列へ戻す例です。

```ts
import { Hex } from "@unikvs/hex";
import { Memory } from "@unikvs/memory";
import UniKvs, { type PlainValue } from "unikvs";

const kvs = UniKvs.config<{ data: PlainValue<Uint8Array<ArrayBuffer>> }>()
  .use(new Hex())
  .persist(new Memory())
  .create();

await kvs.open();

const input = Uint8Array.from([0xde, 0xad, 0xbe, 0xef]);
await kvs.set("data", input);

const output = await kvs.get("data");

await kvs.close();
```

## データ型 [#data-types]

| メソッド       | 入力                      | 出力                      |
| -------------- | ------------------------- | ------------------------- |
| `encode`       | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |
| `decode`       | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |
| `getEncodable` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |
| `getDecodable` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |

- `encode` はバイト列を小文字の hex テキストとして表すバイト列（UTF-8）へ変換します。
- `decode` は hex テキストとして表すバイト列を元のバイト列に戻します。
- 変換後のサイズは元のサイズのちょうど 2 倍になります。
- 空入力は空出力です。
- `0x` の接頭辞は付加も除去もしません。

- チャンクは区切り文字なしで単純に結合されます。
- `getEncodable` は入力チャンクをそれぞれ独立に hex 化して順に送出します。
- `getDecodable` は 2 文字単位で区切って復元し、チャンク境界をまたいだ余り（1 文字）は内部に保持して次のチャンクと結合します。
- 空のストリームと長さ 0 のチャンクは値を 1 つも生成しません。

## エラー [#errors]

このパッケージが投げるエラーは次のとおりです。

### HexDecodeError

#### 意味

入力を hex として解釈できません。奇数長や、`0-9`・`a-f`・`A-F` 以外の文字の混入が原因です。

#### 対処方法

入力が偶数長の hex（`0-9`・`a-f`・`A-F` の連続）か確認してください。`0x` の接頭辞や空白・改行を含めずに渡してください。

#### 例

以下は、`HexDecodeError` を捕捉する例です。

```ts
import { Hex, HexDecodeError } from "@unikvs/hex";

const hex = new Hex();

try {
  hex.decode({ data: new TextEncoder().encode("abc") });
} catch (error) {
  if (error instanceof HexDecodeError) {
    console.log("hex として解釈できません。");
  } else {
    throw error;
  }
}
```

UTF-8 として不正なバイト列は `HexDecodeError` ではなくネイティブの `TypeError` として伝わります。
