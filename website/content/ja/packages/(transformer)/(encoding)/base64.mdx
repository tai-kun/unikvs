## 概要 [#overview]

`@unikvs/base64` は、バイト列を標準の base64 として表すバイト列へ変換する Transformer プラグインです。<Badge>Transformer</Badge>

テキストしか保存できない保存先への格納や、ASCII 文字列としてバイナリーを受け渡す場合に使います。

- 使用する 64 文字は RFC 4648 §4 の `A-Z`・`a-z`・`0-9`・`+`・`/` です。
- 常にオープン状態です。`open`・`close` は不要で、`isOpen` は常に `true`、`name` は常に `"Base64"` を返します。
- Node.js・Bun・ブラウザーで動作し、実行環境による振る舞いの違いはありません。

:::tip
`+`・`/`・`=` は URL やファイル名では区切りと解釈されることがあります。URL に埋め込む値には [`@unikvs/base64url`](/packages/base64url) を使ってください。
:::

インストールは次のコマンドで行います。

```package-install
npm install @unikvs/base64
```

## 使い方 [#usage]

Base64 は ITransformer を実装しています。UniKvs には transform() で渡します。

```ts
import { Base64 } from "@unikvs/base64";
```

コンストラクターの引数は次のとおりです。

以下は、書き込んだ値を base64 化して保存し、読み取り時に元のバイト列へ戻す例です。

```ts
import { Base64 } from "@unikvs/base64";
import { Memory } from "@unikvs/memory";
import UniKvs, { type PlainValue } from "unikvs";

const kvs = UniKvs.config<{ data: PlainValue<Uint8Array<ArrayBuffer>> }>()
  .transform(new Base64())
  .persist(new Memory())
  .create();

await kvs.open();

const input = new TextEncoder().encode("foobar");
await kvs.set("data", input);

const output = await kvs.get("data");

await kvs.close();
```

## データ型 [#data-types]

| メソッド | 入力 | 出力 |
| --- | --- | --- |
| `encode` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |
| `decode` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |
| `getEncodable` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |
| `getDecodable` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |

- `encode` はバイト列を RFC 4648 §4 の base64 テキストとして表すバイト列（UTF-8）へ変換します。
- `decode` は base64 テキストとして表すバイト列を元のバイト列に戻します。
- 変換後のサイズは元のサイズの約 1.37 倍になります。
- `padding: true`（既定）では `=` で埋めた正準形を出力し、`padding: false` では末尾の `=` を省きます。
- 空入力は空出力です。

- チャンクは区切り文字なしで単純に結合されます。
- `getEncodable` は 3 バイト単位で区切って変換し、チャンク境界をまたいだ余り（1〜2 バイト）は内部に保持して次のチャンクと結合します。
- 末尾の `=` の有無はストリーム終了時に確定します。
- `getDecodable` は 4 文字単位で区切って復元し、未完成の文字は内部に保持して次のチャンクと結合します。
- 空のストリームと長さ 0 のチャンクは値を 1 つも生成しません。

## エラー [#errors]

このパッケージが投げるエラーは次のとおりです。

### Base64DecodeError

#### 意味

入力を base64 として解釈できません。`-`・`_` や空白の混入、`=` の位置の誤り、4 で割って 1 余る長さが原因です。

#### 対処方法

入力が base64（`A-Z`・`a-z`・`0-9`・`+`・`/` と末尾の `=`）の連続か確認してください。base64url の値が必要な場合は呼び出し側で変換するか、`@unikvs/base64url` を使ってください。

#### 例

以下は、`Base64DecodeError` を捕捉する例です。

```ts
import { Base64, Base64DecodeError } from "@unikvs/base64";

const base64 = new Base64();

try {
  base64.decode({ data: new TextEncoder().encode("ab-c") });
} catch (error) {
  if (error instanceof Base64DecodeError) {
    console.log("base64 として解釈できません。");
  } else {
    throw error;
  }
}
```

UTF-8 として不正なバイト列は `Base64DecodeError` ではなくネイティブの `TypeError` として伝わります。

### Base64InvalidPaddingError

#### 意味

`padding` が真偽値ではありません。`meta` に `actual` を含みます。

#### 対処方法

`padding` に `true` または `false` を指定するか、省略して既定値を使ってください。
