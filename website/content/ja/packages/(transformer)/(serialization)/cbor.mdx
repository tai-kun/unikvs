## 概要 [#overview]

`@unikvs/cbor` は、JavaScript の値を CBOR（RFC 8949）のバイト列へ変換する Transformer プラグインです。<Badge>Transformer</Badge>

`Date` や `Map`・`Set`・`bigint` などのリッチな型を保ったまま保存する場合に使います。

- [cbor-x](https://github.com/kriszyp/cbor-x) をラップし、`ITransformer` に適合させています。
- 常にオープン状態です。`open`・`close` は不要で、`isOpen` は常に `true`、`name` は常に `"Cbor"` を返します。
- `Date` や `Map` などには cbor-x の拡張タグを使うため、拡張タグを解釈しない相手では生のタグとして見えます。

:::note
拡張タグを解釈できない相手とも相互運用したい場合は、テキストとして内容を確認できる [`@unikvs/superjson`](/packages/superjson) や、素の JSON で十分なときの [`@unikvs/json`](/packages/json) を検討してください。
:::

インストールは次のコマンドで行います。

```package-install
npm install @unikvs/cbor
```

## 使い方 [#usage]

Cbor は ITransformer を実装しています。UniKvs には transform() で渡します。

```ts
import { Cbor } from "@unikvs/cbor";
```

以下は、`Date`・`Map`・`Set` を含む値を CBOR に変換して保存し、型を保ったまま復元する例です。

```ts
import { Cbor } from "@unikvs/cbor";
import { Memory } from "@unikvs/memory";
import UniKvs, { type PlainValue } from "unikvs";

type Snapshot = {
  createdAt: Date;
  counts: Map<string, number>;
  flags: Set<string>;
};

const kvs = UniKvs.config<{ snapshot: PlainValue<Snapshot> }>()
  .connect(new Cbor())
  .persist(new Memory())
  .create();

await kvs.open();

await kvs.set("snapshot", {
  createdAt: new Date("2024-01-02T03:04:05.678Z"),
  counts: new Map([["read", 1]]),
  flags: new Set(["dirty"]),
});

const restored = await kvs.get("snapshot");

await kvs.close();
```

## データ型 [#data-types]

| メソッド       | 入力                      | 出力                      |
| -------------- | ------------------------- | ------------------------- |
| `encode`       | `unknown`                 | `Uint8Array<ArrayBuffer>` |
| `decode`       | `Uint8Array<ArrayBuffer>` | `unknown`                 |
| `getEncodable` | `unknown`                 | `Uint8Array<ArrayBuffer>` |
| `getDecodable` | `Uint8Array<ArrayBuffer>` | `unknown`                 |

- `encode` は任意の値を 1 つの CBOR データアイテムのバイト列へ変換します。
- `decode` は 1 つのデータアイテムのバイト列を値に戻します。
- `null`・真偽値・数値・`bigint`・文字列・配列・プレーンオブジェクト・`Date`・`Map`・`Set`・型付き配列・`RegExp`・`Error` に対応します。
- 関数・シンボルは変換できません。
- シンボルをキーに持つプロパティーは取り除かれます。

- チャンクは区切り文字なしで単純に結合されます。
- `getEncodable` は入力 1 チャンクを 1 つの値としてそれぞれ独立に変換し、出力は複数のデータアイテムを連結した CBOR シーケンス（RFC 8742）です。
- `getDecodable` は 1 つのデータアイテムが完成した時点でその値をすぐに送出し、同じチャンクに複数のアイテムが含まれていれば完成した分から順に送出します。
- 途中で切れたアイテムは内部で保持して次のチャンクと結合します。
- 空のストリームと長さ 0 のチャンクは値を 1 つも生成しません。

## エラー [#errors]

このパッケージが投げるエラーは次のとおりです。

### CborEncodeError

#### 意味

値を CBOR に変換できません。ルート値または入れ子に含まれる関数・シンボルが原因です。元のエラーは `cause` に保持します。

#### 対処方法

関数・シンボルを含まない値へ変換してから保存してください。

#### 例

以下は、`CborEncodeError` を捕捉する例です。

```ts
import { Cbor, CborEncodeError } from "@unikvs/cbor";

const cbor = new Cbor();

try {
  cbor.encode({ data: () => 1 });
} catch (error) {
  if (error instanceof CborEncodeError) {
    console.log(error.cause);
  } else {
    throw error;
  }
}
```

### CborDecodeError

#### 意味

バイト列を CBOR のデータアイテムとして解釈できません。空のバイト列、長さ不定の文字列、後続バイトの混入、ストリーム終了時の未完成アイテムが原因です。元のエラーは `cause` に保持します。

#### 対処方法

入力がこのパッケージの `encode` または `getEncodable` の出力か確認してください。ストリームの出力を単体の `decode` に渡さず、`getDecodable` と組み合わせてください。

#### 例

以下は、`CborDecodeError` を捕捉する例です。

```ts
import { Cbor, CborDecodeError } from "@unikvs/cbor";

const cbor = new Cbor();

try {
  cbor.decode({ data: new Uint8Array(0) });
} catch (error) {
  if (error instanceof CborDecodeError) {
    console.log(error.cause);
  } else {
    throw error;
  }
}
```
