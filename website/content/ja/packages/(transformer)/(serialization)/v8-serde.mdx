## 概要 [#overview]

`@unikvs/v8-serde` は、JavaScript の値を Node.js の `v8.serialize` でバイト列へ変換する Transformer プラグインです。<Badge>Transformer</Badge> <Badge variant="warning">Node.js 専用</Badge>

Structured Clone で扱える値をネイティブ実装で高速に変換し、Node.js 同士のスナップショットやキャッシュに使います。

- `encode`・`decode`・`getEncodable`・`getDecodable` はいずれも非同期で、`await` を付けて呼び出します。
- 常にオープン状態です。`open`・`close` は不要で、`isOpen` は常に `true`、`name` は常に `"V8Serde"` を返します。
- 保存形式は V8 固有のため、ほかのランタイムやほかの言語とは互換性がありません。

:::note
標準のバイナリー形式で相互運用したい場合は [`@unikvs/cbor`](/packages/cbor) を、内容をテキストとして確認したい場合は [`@unikvs/json`](/packages/json) や [`@unikvs/superjson`](/packages/superjson) を検討してください。
:::

インストールは次のコマンドで行います。

```package-install
npm install @unikvs/v8-serde
```

## 使い方 [#usage]

V8Serde は ITransformer を実装しています。UniKvs には transform() で渡します。

```ts
import { V8Serde } from "@unikvs/v8-serde";
```

以下は、`Map` を含む値をバイト列に変換して保存し、元の値に戻す例です。

```ts
import { Memory } from "@unikvs/memory";
import { V8Serde } from "@unikvs/v8-serde";
import UniKvs, { type PlainValue } from "unikvs";

type Snapshot = {
  createdAt: Date;
  counts: Map<string, number>;
};

const kvs = UniKvs.config<{ snapshot: PlainValue<Snapshot> }>()
  .use(new V8Serde())
  .persist(new Memory())
  .create();

await kvs.open();

await kvs.set("snapshot", {
  createdAt: new Date("2024-01-02T03:04:05.678Z"),
  counts: new Map([["read", 1]]),
});

const restored = await kvs.get("snapshot");

await kvs.close();
```

## データ型 [#data-types]

| メソッド       | 入力                      | 出力                                                         |
| -------------- | ------------------------- | ------------------------------------------------------------ |
| `encode`       | `unknown`                 | `Promise<Uint8Array<ArrayBuffer>>`                           |
| `decode`       | `Uint8Array<ArrayBuffer>` | `Promise<unknown>`                                           |
| `getEncodable` | `unknown`                 | `Promise<TransformStream<unknown, Uint8Array<ArrayBuffer>>>` |
| `getDecodable` | `Uint8Array<ArrayBuffer>` | `Promise<TransformStream<Uint8Array<ArrayBuffer>, unknown>>` |

- `encode` は任意の値を `v8.serialize` のバイト列へ変換します。
- `decode` はバイト列を値に戻します。
- `null`・真偽値・数値（`-0` を含む）・`bigint`・文字列・配列・プレーンオブジェクト・`Date`・`Map`・`Set`・型付き配列・`ArrayBuffer`・`DataView`・`Buffer`・`RegExp`・`Error`・循環参照に対応します。
- 関数・シンボル・`WeakMap`・`WeakSet`・`Promise`・`SharedArrayBuffer` は変換できません。

- チャンクは長さ接頭辞付きで単純に結合されます。
- `getEncodable` は入力 1 チャンクを 1 つの値としてそれぞれ独立に変換し、4 バイトの長さと本体を順に送出します。
- `getDecodable` は 1 つの値が完成した時点でその値をすぐに送出し、同じチャンクに複数の値が含まれていれば完成した分から順に送出します。
- 途中で切れた値は内部で保持して次のチャンクと結合します。
- 空のストリームと長さ 0 のチャンクは値を 1 つも生成しません。

## エラー [#errors]

このパッケージが投げるエラーは次のとおりです。

### V8SerdeEncodeError

#### 意味

値をバイト列に変換できません。関数・シンボルなどの未対応値や、ペイロード長の上限超過が原因です。元のエラーは `cause` に保持します。

#### 対処方法

未対応の値を含めずに保存してください。

#### 例

以下は、`V8SerdeEncodeError` を捕捉する例です。

```ts
import { V8Serde, V8SerdeEncodeError } from "@unikvs/v8-serde";

const v8serde = new V8Serde();

try {
  await v8serde.encode({ data: () => 1 });
} catch (error) {
  if (error instanceof V8SerdeEncodeError) {
    console.log(error.cause);
  } else {
    throw error;
  }
}
```

### V8SerdeDecodeError

#### 意味

バイト列を値として解釈できません。不正な形式や、ストリーム終了時の未完成データが原因です。元のエラーは `cause` に保持します。

#### 対処方法

入力がこのパッケージの `encode` の出力か、`getEncodable` と `getDecodable` の組み合わせか確認してください。

#### 例

以下は、`V8SerdeDecodeError` を捕捉する例です。

```ts
import { V8Serde, V8SerdeDecodeError } from "@unikvs/v8-serde";

const v8serde = new V8Serde();

try {
  await v8serde.decode({ data: new Uint8Array(0) });
} catch (error) {
  if (error instanceof V8SerdeDecodeError) {
    console.log(error.cause);
  } else {
    throw error;
  }
}
```

### UnsupportedRuntimeError

#### 意味

Node.js 以外のランタイムで使われました。`@unikvs/core` の共通エラーです。

#### 対処方法

Node.js で実行するか、ほかのランタイムでも動作する `@unikvs/cbor`・`@unikvs/json`・`@unikvs/superjson` を使ってください。
