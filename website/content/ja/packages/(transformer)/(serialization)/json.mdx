## 概要 [#overview]

`@unikvs/json` は、値を標準の `JSON.stringify` と `JSON.parse` でシリアライズする Transformer プラグインです。<Badge>Transformer</Badge>

JSON で表現できるプレーンな値をテキストとして保存する場合に使います。

- 一括変換では 1 つの値を 1 つの JSON 文字列として扱い、ストリームでは JSON Lines（JSONL / NDJSON）として 1 行に 1 つの値を扱います。
- 常にオープン状態です。`open`・`close` は不要で、`isOpen` は常に `true`、`name` は常に `"Json"` を返します。
- 追加の依存はなく、実行環境の `TextEncoder`・`TextDecoder` と JSON API だけで動作します。

:::tip
`Date` を日付のまま、`BigInt` や `Map`・`Set` を型を保ったまま往復したい場合は [`@unikvs/superjson`](/packages/superjson) を使ってください。バイナリー形式でより小さく保存したい場合は [`@unikvs/cbor`](/packages/cbor) を検討してください。
:::

インストールは次のコマンドで行います。

```package-install
npm install @unikvs/json
```

## 使い方 [#usage]

Json は ITransformer を実装しています。UniKvs には transform() で渡します。

```ts
import { Json } from "@unikvs/json";
```

以下は、オブジェクトを JSON に変換して保存し、読み取り時に復元する例です。

```ts
import { Json } from "@unikvs/json";
import { Memory } from "@unikvs/memory";
import UniKvs, { type PlainValue } from "unikvs";

type Profile = {
  name: string;
  tags: string[];
};

const kvs = UniKvs.config<{ profile: PlainValue<Profile> }>()
  .use(new Json())
  .persist(new Memory())
  .create();

await kvs.open();

await kvs.set("profile", { name: "tai-kun", tags: ["json", "transformer"] });

const profile = await kvs.get("profile");

await kvs.close();
```

## データ型 [#data-types]

| メソッド       | 入力                      | 出力                      |
| -------------- | ------------------------- | ------------------------- |
| `encode`       | `unknown`                 | `Uint8Array<ArrayBuffer>` |
| `decode`       | `Uint8Array<ArrayBuffer>` | `unknown`                 |
| `getEncodable` | `unknown`                 | `Uint8Array<ArrayBuffer>` |
| `getDecodable` | `Uint8Array<ArrayBuffer>` | `unknown`                 |

- `encode` は値を JSON 文字列のバイト列（UTF-8）へ変換します。
- `decode` は JSON 文字列のバイト列を値へ変換します。
- `null`・真偽値・数値・文字列・配列・プレーンオブジェクトに対応します。
- `Date` は ISO 8601 文字列になり、`Map`・`Set` は空のオブジェクトになります。
- `undefined`・関数・シンボルはルート値では変換できず、入れ子ではプロパティーごと省略されます。

- チャンクは改行（`\n`）区切りで接続されます。
- `getEncodable` は入力 1 チャンクを 1 つの値として `JSON.stringify` し、末尾に `\n` を付けて出力します。
- `getDecodable` は `\n` で区切って 1 行ずつ `JSON.parse` し、行末の `\r` を 1 つだけ取り除きます。
- 完全に空の行は読み飛ばし、最終行は末尾の改行がなくても処理します。
- 行の区切りが任意のバイト境界で分割されても復元できます。
- 空のストリームは値を 1 つも出力しません。

## エラー [#errors]

このパッケージが投げるエラーは次のとおりです。

### JsonUnsupportedValueError

#### 意味

ルートの値が `undefined`・関数・シンボルで、JSON にシリアライズできません。`meta.type` に `typeof` の結果を保持します。

#### 対処方法

`null` に置き換えるか、JSON で表現できる値へ変換してください。

#### 例

以下は、`JsonUnsupportedValueError` を捕捉する例です。

```ts
import { Json, JsonUnsupportedValueError } from "@unikvs/json";

const json = new Json();

try {
  json.encode({ data: undefined });
} catch (error) {
  if (error instanceof JsonUnsupportedValueError) {
    console.log(error.meta.type);
  } else {
    throw error;
  }
}
```

`BigInt` の変換失敗はネイティブの `TypeError`、`decode` の失敗は不正な JSON・空入力・後続バイトでは `SyntaxError`、不正な UTF-8 では `TypeError` として伝わります。ストリームのデコードで不正な行を流すと `SyntaxError` で失敗します。
