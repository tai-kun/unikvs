## 概要 [#overview]

`@unikvs/passthrough` は、入力を何も変換せずそのまま透過させる Transformer プラグインです。<Badge>Transformer</Badge>

条件分岐でトランスフォーマーをオン・オフしたい場合に、パイプラインの構成を変えずに変換の有無を切り替えるために使います。

- `encode`・`decode` は受け取ったデータをそのまま返します。
- 常にオープン状態です。`open`・`close` は不要で、`isOpen` は常に `true`、`name` は常に `"PassThrough"` を返します。

:::note
ログを記録したい場合は、代わりに [`@unikvs/debug`](/packages/debug) を使ってください。このパッケージはログの出力も変数の参照も行いません。
:::

インストールは次のコマンドで行います。

```package-install
npm install @unikvs/passthrough
```

## 使い方 [#usage]

PassThrough は ITransformer を実装しています。UniKvs には transform() で渡します。

```ts
import { PassThrough } from "@unikvs/passthrough";
```

以下は、変換をせずに値をそのまま保存する例です。

```ts
import { Memory } from "@unikvs/memory";
import { PassThrough } from "@unikvs/passthrough";
import { UniKvs, type PlainValue } from "unikvs";

const kvs = UniKvs.config<{ greeting: PlainValue<string> }>()
  .transform(new PassThrough())
  .persist(new Memory())
  .create();

await kvs.open();

await kvs.set("greeting", "hello");
const greeting = await kvs.get("greeting");

await kvs.close();
```

## データ型 [#data-types]

| メソッド | 入力 | 出力 |
| --- | --- | --- |
| `encode` | `TData` | `TData` |
| `decode` | `TData` | `TData` |
| `getEncodable` | `any` | `any` |
| `getDecodable` | `any` | `any` |

- `encode`・`decode` は任意の型のデータをそのまま返します。
- `getEncodable`・`getDecodable` はチャンクをそのまま流す `TransformStream` を返します。
- データの内容にもチャンクの分割にも影響しません。

- チャンクは区切り文字なしで単純に透過します。
- チャンクの境界も参照も変わりません。
- 空のストリームは空のまま完了します。

## エラー [#errors]

このパッケージ固有のエラーはありません。データを変換しないため、単体で使っても保存される値は変わりません。
