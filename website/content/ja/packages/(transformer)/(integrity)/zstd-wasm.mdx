## 概要 [#overview]

`@unikvs/zstd.wasm` は、バイト列を透過的に圧縮・展開する Transformer プラグインです。<Badge>Transformer</Badge>

容量の大きなバイナリーやバックアップを小さく保存したい場合に使います。

- Zstandard で可逆圧縮し、保存容量を削減します。
- 圧縮レベルは `1`〜`22` で、既定は `3` です。数値を上げるほど圧縮率は高まりますが、そのぶん圧縮に時間がかかります。
- `open` で初期化してから使います。
- 初期化に成功すると、`isOpen` は `true` を、`name` は常に `"ZstdWasm"` を返します。

:::warning
このパッケージで圧縮したバイト列は、[`@unikvs/compression`](/packages/compression) など他の形式では展開できません。
:::

インストールは次のコマンドで行います。

```package-install
npm install @unikvs/zstd.wasm
```

## 使い方 [#usage]

ZstdWasm は ITransformer を実装しています。UniKvs には transform() で渡します。

```ts
import { ZstdWasm } from "@unikvs/zstd.wasm";
```

コンストラクターの引数は次のとおりです。

<TypeTable
  type={{
    options: {
      type: "ZstdWasmOptions",
      description: "圧縮の設定です。省略時は既定値で動作します。",
    },
    "options.level": {
      type: "number",
      default: "3",
      description: "圧縮レベルです。1〜22 の整数を指定します。",
    },
  }}
/>

以下は、書き込んだ値を Zstandard で圧縮して保存し、読み取り時に展開する例です。

```ts
import { Memory } from "@unikvs/memory";
import { ZstdWasm } from "@unikvs/zstd.wasm";
import UniKvs, { type PlainValue } from "unikvs";

const kvs = UniKvs.config<{ data: PlainValue<Uint8Array<ArrayBuffer>> }>()
  .transform(new ZstdWasm())
  .persist(new Memory())
  .create();

await kvs.open();

const input = new TextEncoder().encode("Repeat this text. ".repeat(100));
await kvs.set("data", input);

const output = await kvs.get("data");

await kvs.close();
```

## データ型 [#data-types]

| メソッド | 入力                      | 出力                               |
| -------- | ------------------------- | ---------------------------------- |
| `encode` | `Uint8Array<ArrayBuffer>` | `Promise<Uint8Array<ArrayBuffer>>` |
| `decode` | `Uint8Array<ArrayBuffer>` | `Promise<Uint8Array<ArrayBuffer>>` |

- `encode` はバイト列を圧縮します。
- `decode` は圧縮済みのバイト列を展開します。
- `decode` が失敗した場合は、上流のエラーをそのまま投げます。
- 一括変換はどちらも非同期のため、`await` を付けて呼び出します。
- ストリーム API（`getEncodable`・`getDecodable`）はありません。
- 反復的なテキストは圧縮で小さくなりやすい一方、圧縮済みや乱数的なデータは小さくなりにくい傾向があります。
- 圧縮で小さくならなかった場合でも、展開すれば元のバイト列に戻ります。

## エラー [#errors]

このパッケージが投げるエラーは次のとおりです。

### ZstdWasmInvalidLevelError

#### 意味

圧縮レベルが `1`〜`22` の整数以外の場合に投げられます。

#### 対処方法

`1`〜`22` の整数を指定してください。省略した場合は `3` で動作します。

### ZstdWasmInitError

#### 意味

モジュールの初期化に失敗した場合に投げられます。

#### 対処方法

実行環境を確認したうえで、`open` を再度実行してください。
