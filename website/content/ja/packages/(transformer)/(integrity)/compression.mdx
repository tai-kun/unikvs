## 概要 [#overview]

`@unikvs/compression` は、バイト列を透過的に圧縮・展開する Transformer プラグインです。<Badge>Transformer</Badge>

保存容量を削減したい場合に使います。

- Web 標準の `CompressionStream` と `DecompressionStream` をラップし、`ITransformer` に適合させています。
- 対応形式は `gzip`・`deflate`・`deflate-raw` で、互換性を重視するなら `gzip` を選びます。
- 常にオープン状態です。`open`・`close` は不要で、`isOpen` は常に `true`、`name` は常に `"Compression"` を返します。

:::warning
1 つの KVS では 1 つの形式に統一してください。圧縮時と展開時で形式が異なると展開できないほか、[`@unikvs/zstd.wasm`](/packages/zstd-wasm) や [`@unikvs/zstd.node`](/packages/zstd.node) で圧縮したバイト列も展開できません。
:::

インストールは次のコマンドで行います。

```package-install
npm install @unikvs/compression
```

## 使い方 [#usage]

Compression は ITransformer を実装しています。UniKvs には transform() で渡します。

```ts
import { Compression } from "@unikvs/compression";
```

コンストラクターの引数は次のとおりです。

<TypeTable
  type={{
    format: {
      type: '"gzip" | "deflate" | "deflate-raw"',
      required: true,
      description: "圧縮形式です。展開時も同じ形式で往復してください。",
    },
  }}
/>

以下は、書き込んだ値を gzip で圧縮して保存し、読み取り時に展開する例です。

```ts
import { Compression } from "@unikvs/compression";
import { Memory } from "@unikvs/memory";
import UniKvs, { type PlainValue } from "unikvs";

const kvs = UniKvs.config<{ data: PlainValue<Uint8Array<ArrayBuffer>> }>()
  .transform(new Compression("gzip"))
  .persist(new Memory())
  .create();

await kvs.open();

const input = new TextEncoder().encode("Repeat this text. ".repeat(100));
await kvs.set("data", input);

const output = await kvs.get("data");

await kvs.close();
```

## データ型 [#data-types]

| メソッド       | 入力                      | 出力                               |
| -------------- | ------------------------- | ---------------------------------- |
| `encode`       | `Uint8Array<ArrayBuffer>` | `Promise<Uint8Array<ArrayBuffer>>` |
| `decode`       | `Uint8Array<ArrayBuffer>` | `Promise<Uint8Array<ArrayBuffer>>` |
| `getEncodable` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>`          |
| `getDecodable` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>`          |

- `encode` はバイト列を圧縮します。
- `decode` は圧縮済みのバイト列を展開します。
- 一括変換はどちらも非同期のため、`await` を付けて呼び出します。
- 反復的なテキストは圧縮で小さくなりやすい一方、圧縮済みや乱数的なデータは小さくなりにくい傾向があります。
- 圧縮で小さくならなかった場合でも、展開すれば元のバイト列に戻ります。

- チャンクは区切り文字なしで単純に結合されます。
- `getEncodable` は `CompressionStream` をそのまま返します。
- `getDecodable` は `DecompressionStream` をそのまま返します。
- 不揃いな複数チャンクでも、往復後は元のバイト列に戻ります。

## エラー [#errors]

このパッケージ固有のエラーはありません。実行環境が対応していない形式を指定した場合は、`CompressionStream` または `DecompressionStream` の構築時にネイティブの `TypeError` が投げられます。非圧縮のバイト列を `decode` に渡した場合も展開に失敗します。そのため、圧縮時と展開時で形式を統一してください。
