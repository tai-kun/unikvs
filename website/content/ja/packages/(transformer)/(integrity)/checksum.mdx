## 概要 [#overview]

`@unikvs/checksum` は、バイト列のハッシュ値を計算し、変数に設定した期待値と照合する Transformer プラグインです。<Badge>Transformer</Badge>

保存したデータの破損や改ざんを検知する場合に使います。

- 対応アルゴリズムは MD5・SHA-1・SHA-224・SHA-256・SHA-384・SHA-512 の 6 種類で、クラス（`ChecksumMd5` など）と変数キーが 1 対 1 に対応します。
- 検証に成功してもデータを変えず、そのまま返します。
- 常にオープン状態です。`open`・`close` は不要で、`isOpen` は常に `true` を返します。

:::tip
キーは文字列を直書きせず、`ChecksumSha256.CHECKSUM_VAR_NAME` のように静的プロパティーから参照してください。対応誤りを防げます。
:::

インストールは次のコマンドで行います。

```package-install
npm install @unikvs/checksum @noble/hashes@2.0.0
```

## 使い方 [#usage]

ChecksumSha256 は ITransformer を実装しています。UniKvs には transform() で渡します。

```ts
import { ChecksumSha256 } from "@unikvs/checksum";
```

コンストラクターの引数は次のとおりです。

<TypeTable
  type={{
    options: {
      type: "ChecksumOptions",
      description: "検証の必須化の設定です。省略時は検証なしで透過します。",
    },
    "options.required": {
      type: "boolean",
      default: "false",
      description: "変数にチェックサムがない場合にエラーを投げるかどうかです。",
    },
  }}
/>

以下は、SHA-256 の期待値を変数で渡して検証しながら読み書きする例です。

```ts
import { ChecksumSha256 } from "@unikvs/checksum";
import { Memory } from "@unikvs/memory";
import UniKvs, { type PlainValue } from "unikvs";

const kvs = UniKvs.config<{ data: PlainValue<Uint8Array<ArrayBuffer>> }>()
  .transform(new ChecksumSha256({ required: true }))
  .persist(new Memory())
  .create();

await kvs.open();

await kvs.set(
  "data",
  new TextEncoder().encode("test"),
  {
    [ChecksumSha256.CHECKSUM_VAR_NAME]:
      "9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08",
  },
);

const output = await kvs.get("data", {
  [ChecksumSha256.CHECKSUM_VAR_NAME]:
    "9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08",
});

await kvs.close();
```

## データ型 [#data-types]

| メソッド | 入力 | 出力 |
| --- | --- | --- |
| `encode` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |
| `decode` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |
| `getEncodable` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |
| `getDecodable` | `Uint8Array<ArrayBuffer>` | `Uint8Array<ArrayBuffer>` |

- `encode`・`decode` は同じ一括検証を行い、書き込みと読み取りで処理は変わりません。
- `getEncodable`・`getDecodable` は同じストリーム検証を行います。
- データ自体は変換せず、変数キー（たとえば `ChecksumSha256.CHECKSUM_VAR_NAME`）に対応する 16 進文字列と、計算したハッシュ値を比較します。
- 変数に文字列がなければ、`required: true` ではエラーを投げ、`false`（既定）では計算を省略してそのまま返します。

- チャンクは区切り文字なしで単純に結合されます。
- ストリーム検証では各チャンクをそのまま下流へ流しながらハッシュを更新し、終了時の `flush` で期待値と比較します。
- チェックサムがない場合は透過する `TransformStream` を返します。

## エラー [#errors]

このパッケージが投げるエラーは次のとおりです。

### ChecksumMismatchError

#### 意味

ハッシュが期待値と一致しません。`meta` に `actual` と `expected` を含みます。

#### 対処方法

期待値の指定誤りかデータの破損を確認し、`meta.actual` と `meta.expected` を比べて切り分けてください。

#### 例

以下は、`ChecksumMismatchError` を捕捉する例です。

```ts
import { ChecksumMismatchError, ChecksumSha256 } from "@unikvs/checksum";

const transformer = new ChecksumSha256();

try {
  transformer.encode({
    vars: { [ChecksumSha256.CHECKSUM_VAR_NAME]: "0".repeat(64) },
    data: new TextEncoder().encode("test"),
  });
} catch (error) {
  if (error instanceof ChecksumMismatchError) {
    console.log(error.meta.expected);
    console.log(error.meta.actual);
  } else {
    throw error;
  }
}
```

### ChecksumRequiredError

#### 意味

`required: true` なのに、`vars` に文字列のチェックサムがありません。

#### 対処方法

変数キーに 16 進文字列を設定するか、`required` を `false` にしてください。

### ChecksumInvalidVarNameError

#### 意味

`CHECKSUM_VAR_NAME` が文字列ではありません。通常のサブクラスでは発生しません。

#### 対処方法

基底クラスを独自継承した場合に静的プロパティーを確認してください。

### ChecksumInvalidRequiredError

#### 意味

`required` が真偽値ではありません。`meta` に `actual` を含みます。

#### 対処方法

`required` に `true` または `false` を指定するか、省略して既定値（`false`）を使ってください。
