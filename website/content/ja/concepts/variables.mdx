実行時変数は、操作の挙動を切り替える実行時コンテキストです。操作ごとの `vars` で渡します。型レベルの設定 (マッピングやスキーマ) が静的なのに対し、変数は操作単位で動的に組み替えられます。

```ts
await kvs.set("message", "hello", {
  vars: { region: "us-east-1" },
});
```

チェックサムのハッシュ値を操作ごとに switch するような使い方が典型です。トランスフォーマーとストレージの実装側では、変数を使って挙動を切り替えられます。

## Variables クラス [#variables-class]

プラグインに渡される `Variables` は Map ライクなクラスで、`get`・`set` で読み書きし、`setReadonly` で変更禁止にできます。

```ts
import { Variables } from "@unikvs/core";

const vars = Variables.from({
  locale: "ja",
  retryCount: 3,
});

vars.set("traceId", "xxx");
vars.get("locale");
vars.setReadonly("tenant", "acme");
```

操作への入力は `Record`・`Map`・エントリー配列・`Variables` のいずれでも指定できます。`Variables.from` で正規化されます。

## 旧 Record 形式からの移行 [#migration]

| 旧                         | 新                                                           |
| -------------------------- | ------------------------------------------------------------ |
| `vars.foo` / `vars["foo"]` | `vars.get("foo")`                                            |
| `vars.foo = value`         | `vars.set("foo", value)`                                     |
| `{ ...vars, a: 1 }`        | `vars.clone().set("a", 1)`                                   |
| `Object.entries(vars)`     | `[...vars.entries()]` / `vars.toObject()`                    |
| リテラル入力               | `Variables.from(input)` (入力としては従来どおり `Record` 可) |

## 予約キー [#reserved-keys]

`unikvs:*` は予約キーです。利用者側で設定しないでください。操作ごとに UniKvs が付与・上書きします。read-repair の書き戻し要求は実行時変数ではなく、`get`・`stream` のコンテキストの `repair` フィールドで伝えます。書き戻しの詳細は[複数ストレージ](/guides/multi-storage)を参照してください。
