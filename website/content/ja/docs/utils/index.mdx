## 概要

`@unikvs/utils` は、UniKVS のプラグインパッケージ群で共有されるユーティリティー集です。

一般の利用者が直接インポートする場面はほとんどありませんが、独自プラグインを実装する際に再利用できます。

```package-install
pnpm add @unikvs/utils
```

## 関数一覧

| 関数                     | 説明                                                                                       |
| ------------------------ | ------------------------------------------------------------------------------------------ |
| `bytesToHex(bytes)`      | `Uint8Array` を 16 進数文字列へ変換します。`toHex()` 実装がある環境ではそれを利用します。   |
| `chunks(data, maxSize)`  | バイナリーデータを指定バイトサイズ以下のチャンクへ分割するジェネレーターです。             |
| `toReadableStream(iterable)` | 反復可能なデータから `ReadableStream` を作成します。                                    |
| `withReadableStreamFrom(...)` | ソースから `ReadableStream` を構築し、破棄時の後処理を扱うヘルパーです。               |
| `isValidFilename(name)`  | ファイル名として安全かどうか (255 バイト以内、予約語・制御文字なし、正規化整合など) を判定します。 |
| `assertValidFilename(name)` | `isValidFilename()` が false の場合に `InvalidFilenameError` を投げます。                |
| `isValidDirname(name)`   | ディレクトリー名として安全かどうかを判定します。                                           |
| `assertValidDirname(name)` | `isValidDirname()` が false の場合に `InvalidDirnameError` を投げます。                   |

## エラー

| クラス名               | 説明                                       |
| ---------------------- | ------------------------------------------ |
| `InvalidFilenameError` | ファイル名として無効な文字列が渡された。   |
| `InvalidDirnameError`  | ディレクトリー名として無効な文字列が渡された。 |

## 使用例

チェックサム検証でハッシュ値を 16 進数文字列として比較する例です。

```ts hex.ts
import { bytesToHex, chunks } from "@unikvs/utils";

const hex = bytesToHex(new Uint8Array([0xde, 0xad])); // "dead"

// 大きなバッファーを 1 MiB ずつ処理する
for (const chunk of chunks(largeBuffer, 1024 * 1024)) {
  process(chunk);
}
```

ファイル名検証は [@unikvs/fs.node](/ja/docs/fs.node/) と [@unikvs/opfs](/ja/docs/opfs/) のストレージ実装でも使われています。キーの命名規則の詳細は各ストレージのドキュメントを参照してください。
