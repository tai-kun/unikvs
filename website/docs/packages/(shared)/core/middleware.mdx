## 概要 [#overview]

`IMiddleware` はミドルウェアが実装するインターフェースです。`name` と `isOpen` のみ必須で、フックはすべて任意です。必要なフックだけを実装します。

```ts
import type { IMiddleware } from "@unikvs/core";

type MyMiddleware = IMiddleware<string, string, ArrayBuffer, ArrayBuffer>;
```

## 型引数 [#type-params]

| 型引数         | 既定値 | 対応するフック                    |
| -------------- | ------ | --------------------------------- |
| `TEncodeData`  | `any`  | `encode` の入力と `decode` の出力 |
| `TDecodeData`  | `any`  | `decode` の入力と `encode` の出力 |
| `TEncodeChunk` | `any`  | `encodeStream` の入出力           |
| `TDecodeChunk` | `any`  | `decodeStream` の入出力           |

`encode` で生データを保存形式に変換し、`decode` で逆変換します。データ変換とストリーム変換で型引数が分かれているため、値とチャンクの型が異なるプラグインも表現できます。

## 基本プロパティー [#identity]

| メンバー | 必須 | 説明               |
| -------- | ---- | ------------------ |
| `name`   | 必須 | プラグイン名       |
| `isOpen` | 必須 | 初期化済みかどうか |

`open(c)` と `close(c)` は任意です。[ストレージのライフサイクル](./storage#identity)と同じく、必要な場合のみ実装します。

## フック [#hooks]

| フック         | 引数                          | 説明                           |
| -------------- | ----------------------------- | ------------------------------ |
| `mapKey`       | `MapKeyContext`               | キーを変換して `string` を返す |
| `open`         | `OpenContext`                 | 初期化処理                     |
| `close`        | `CloseContext`                | 終了処理                       |
| `use`          | `UseContext`, `next`          | 読み書き操作の前後処理         |
| `encode`       | `EncodeContext`, `next`       | 書き込みデータの変換           |
| `decode`       | `DecodeContext`, `next`       | 読み取りデータの逆変換         |
| `encodeStream` | `EncodeStreamContext`, `next` | 書き込みストリームの変換       |
| `decodeStream` | `DecodeStreamContext`, `next` | 読み取りストリームの逆変換     |

### `mapKey` [#hooks-map-key]

キーそのものを変換します。同期的に `string` を返します。他のフックと異なり `next` はありません。

### `use` [#hooks-use]

読み書き操作 (`set`・`get`・`stream`・`has`・`delete`・`clear`) の前後処理です。`action` で絞り込むと、各操作の `key` や `repair` に型安全に触れます。

```ts
import type { IMiddleware } from "@unikvs/core";

export class Timing implements IMiddleware {
  public readonly name = "Timing";
  public isOpen = false;

  public async use(c: IMiddleware.UseContext, next: IMiddleware.INext): Promise<void> {
    const startedAt = Date.now();
    await next();
    console.log(`${c.action} took ${Date.now() - startedAt}ms`);
  }
}
```

### `encode` と `decode` [#hooks-encode-decode]

データの変換と逆変換です。`source` が入力で、`destination` に結果を代入します。

```ts
import type { IMiddleware } from "@unikvs/core";

export class UpperCase implements IMiddleware<string> {
  public readonly name = "UpperCase";
  public isOpen = false;

  public async encode(
    c: IMiddleware.EncodeContext<string>,
    next: IMiddleware.INext,
  ): Promise<void> {
    c.destination = c.source.toUpperCase();
    await next();
  }

  public async decode(
    c: IMiddleware.DecodeContext<string>,
    next: IMiddleware.INext,
  ): Promise<void> {
    c.destination = c.source.toLowerCase();
    await next();
  }
}
```

`EncodeContext<string>` は `IEncodeContext<string, string>` と等価です。型引数を 1 つだけ渡すと、入出力が同じ型として解決されます。

### `encodeStream` と `decodeStream` [#hooks-encode-decode-stream]

ストリームの変換と逆変換です。データ変換と異なり、`source` と `destination` は [`IReadableStream`](./stream) です。

## `next` [#next]

`use`・`encode`・`decode`・`encodeStream`・`decodeStream` は `next()` を呼ぶと後段へ進みます。`INext` は引数なしで `Promise<void>` を返します。

```ts
public async use(c: IMiddleware.UseContext, next: IMiddleware.INext): Promise<void> {
  await next(); // 後段へ進む
}
```

`next()` の前後で前処理と後処理を書けます。戻り値は `PromiseLike<void>` で、`MaybePromise` ではなく必ず非同期として扱われます。

:::warning[同期・非同期の混在に注意]
`open`・`close` の戻り値は `MaybePromise<void>` ですが、`use` 系の戻り値は `PromiseLike<void>` です。`open()` 前の呼び出しや未対応の操作は各プラグインが適切なエラーを投げます。
:::

## コンテキストの別名 [#contexts]

`IMiddleware` 名前空間は [パイプラインコンテキスト](./pipeline-context#contexts) の別名を提供します。

| 別名                                 | 実体                                                                                             |
| ------------------------------------ | ------------------------------------------------------------------------------------------------ |
| `IMiddleware.MapKeyContext`          | [`IMapKeyContext`](./pipeline-context#imapkeycontext)                                            |
| `IMiddleware.OpenContext`            | [`IOpenContext`](./pipeline-context#iopencontext)                                                |
| `IMiddleware.CloseContext`           | [`ICloseContext`](./pipeline-context#iclosecontext)                                              |
| `IMiddleware.UseContext`             | `ISetContext \| IGetContext \| IStreamContext \| IHasContext \| IDeleteContext \| IClearContext` |
| `IMiddleware.EncodeContext<T>`       | [`IEncodeContext<T, T>`](./pipeline-context#iencodecontext)                                      |
| `IMiddleware.DecodeContext<T>`       | [`IDecodeContext<T, T>`](./pipeline-context#idecodecontext)                                      |
| `IMiddleware.EncodeStreamContext<T>` | [`IEncodeStreamContext<T, T>`](./pipeline-context#iencodestreamcontext)                          |
| `IMiddleware.DecodeStreamContext<T>` | [`IDecodeStreamContext<T, T>`](./pipeline-context#idecodestreamcontext)                          |
