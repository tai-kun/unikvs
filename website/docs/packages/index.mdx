UniKVS は本体パッケージと、プラグインと補助のパッケージから構成されます。本体の `unikvs` 以外は、目的に合わせてインストールします。

インストール方法は[インストール](/how-to/installation)を、保存先の選び方は[ストレージ比較](/reference/comparison)を参照してください。

## ミドルウェア [#middleware]

値を透過的に変換します。変換内容ごとに分かれています。

<CardGroup cols={2}>
  <Card title="@unikvs/json" href="./json" icon="braces">
    値を JSON に、ストリームでは JSON Lines に変換します。
  </Card>
  <Card title="@unikvs/superjson" href="./superjson" icon="boxes">
    Date・Map・Set・BigInt・undefined を保持したまま SuperJSON で変換します。
  </Card>
  <Card title="@unikvs/cbor" href="./cbor" icon="binary">
    値を CBOR に、ストリームでは CBOR シーケンスに変換します。
  </Card>
  <Card title="@unikvs/v8-serde" href="./v8-serde" icon="binary">
    Node.js の v8.serialize で値を高速にシリアライズします。
  </Card>
  <Card title="@unikvs/base64" href="./base64" icon="file-code">
    バイト列を Base64 のテキストに変換します。
  </Card>
  <Card title="@unikvs/base64url" href="./base64url" icon="file-code">
    バイト列を URL セーフな Base64url に変換します。
  </Card>
  <Card title="@unikvs/hex" href="./hex" icon="file-code">
    バイト列を 16 進数文字列 (Hex) に変換します。
  </Card>
  <Card title="@unikvs/compression" href="./compression" icon="archive">
    gzip・deflate・deflate-raw による圧縮と展開を行います。
  </Card>
  <Card title="@unikvs/checksum" href="./checksum" icon="shield-check">
    MD5・SHA-1・SHA-224・SHA-256・SHA-384・SHA-512 の検証を行います。
  </Card>
  <Card title="@unikvs/zstd.wasm" href="./zstd-wasm" icon="archive">
    WASM 版 zstd による圧縮と展開を行います。
  </Card>
  <Card title="@unikvs/zstd.node" href="./zstd-node" icon="archive">
    Node.js の zstd による圧縮と展開を行います。
  </Card>
  <Card title="@unikvs/zstd.bun" href="./zstd-bun" icon="archive">
    Bun の zstd による圧縮と展開を行います。
  </Card>
  <Card title="@unikvs/brotli.node" href="./brotli-node" icon="archive">
    Node.js の Brotli による圧縮と展開を行います。
  </Card>
  <Card title="@unikvs/brotli.bun" href="./brotli-bun" icon="archive">
    Bun の Brotli による圧縮と展開を行います。

  <Card title="@unikvs/brotli.wasm" href="./brotli-wasm" icon="archive">

  </Card>
