## 概要 [#overview]

`unikvs` はメインクライアントのパッケージです。<Badge>メインクライアント</Badge> ビルダー (`Builder` / `UniKvsBuilder`) でミドルウェアとストレージを組み立て、生成したクライアント (`UniKvs`) で読み書きします。

```package-install
npm i unikvs
```

## ビルダー [#builder]

`new Builder()` でビルダーを作ります。型パラメーターでマッピングを直接指定する方法と、`schema` オプションで Valibot スキーマから推論させる方法があります。後者では入出力値の実行時検証も有効になります。

<Tabs>
  <Tab title="schemaあり">
    `PlainValue()`・`StreamValue()`・`Value()` に Valibot スキーマを渡します。マッピング型は自動推論します。Valibot スキーマを使う場合は `valibot` を別途インストールします。

    ```ts
    import * as unikvs from "unikvs";
    import * as v from "valibot";

    const kvs = new unikvs.Builder({
      schema: {
        foo: unikvs.PlainValue(v.instance(Uint8Array)),
      },
    })
      .persist(storage)
      .build();
    ```

    動的キーには配列形式を使います。キースキーマと値スキーマの組を並べ、最初に一致した定義を採用します。

    ```ts
    import * as unikvs from "unikvs";
    import * as v from "valibot";

    const kvs = new unikvs.Builder({
      schema: [
        [v.pipe(v.string(), v.regex(/^msg-.+/)), unikvs.PlainValue(v.string())],
        [v.pipe(v.string(), v.regex(/^img-.+/)), unikvs.StreamValue(v.instance(Uint8Array))],
      ],
    })
      .persist(storage)
      .build();
    ```

  </Tab>
  <Tab title="schemaなし">
    `T` はキーから値へのマッピング (`{ [key]: PlainValue | StreamValue | Value }`) で、キーごとに使える操作が型レベルで決まります。実行時の検証は行いません。

    ```ts
    import * as unikvs from "unikvs";

    const kvs = new unikvs.Builder<{
      foo: unikvs.Value<Uint8Array>;
    }>()
      .persist(storage)
      .build();
    ```

  </Tab>
</Tabs>

:::warning[スキーマ定義が不正な場合]
`schema` の形式が不正な場合はコンストラクターの時点で `InvalidInputError` を投げます。
:::

設定は以下の順序で行います。

<Steps>
  <Step title="`use(middleware)`">
    ミドルウェアを追加します (任意)。ストレージ登録後にも追加できます。
  </Step>
  <Step title="`persist(storage)`">ストレージを追加します (必須、複数可)。</Step>
  <Step title="`fork(branch)`">
    分岐したパイプラインでストレージを追加します
    (任意)。分岐先での追加は親パイプラインに漏れません。
  </Step>
  <Step title="`build(options?)`">
    `UniKvs` クライアントを作ります。`options.beforeAll` で先頭、`options.beforeStorage`
    で全ストレージの直前にミドルウェアを挿入できます。ストレージがなければ `MissingStorageError`
    を投げます。
  </Step>
</Steps>

:::warning[ストレージ未登録に注意]
`build()` の前に `persist()` を少なくとも 1 回呼んでください。
:::

各ストレージは、`persist()` 呼び出し時点のパイプラインのスナップショットを使います。

書き込みはすべてのストレージに並列で行い、読み取りは見つかったストレージの前段を逆順に適用してデコードします。

### 分岐 [#builder-fork]

`fork()` で分岐したパイプラインにストレージを追加できます。分岐は `new Branch()` で作ります。分岐先での追加は親パイプラインに漏れません。

以下は、分岐先と親に別々のストレージを登録する例です。

```ts
import * as unikvs from "unikvs";

const kvs = new unikvs.Builder({
  vars: {},
  schema: {},
})
  .use(new Middleware())
  .fork(new unikvs.Branch().use(new Middleware()).persist(new Storage()))
  .persist(new Storage())
  .build();
```

### 先頭のミドルウェア [#builder-before-all]

`build()` の `beforeAll` にミドルウェアの配列を渡すと、構成済みのすべてのミドルウェアより前に挿入されます。メインのパイプラインと `fork()` したすべての分岐が対象です。利用側のデータに最も近い位置で共通の変換を適用したい場合に使えます。

```ts
const kvs = new unikvs.Builder()
  .use(new Middleware())
  .persist(storage)
  .build({ beforeAll: [new Middleware()] });
```

配列の先頭ほど手前、末尾ほど後続のミドルウェアに近づくように挿入されます。

### ストレージ直前のミドルウェア [#builder-before-storage]

`build()` の `beforeStorage` にミドルウェアの配列を渡すと、構成済みのすべてのストレージの直前に挿入されます。メインのパイプラインと `fork()` したすべての分岐が対象です。複数のストレージへ共通の変換を最後に適用したい場合に使えます。

```ts
const kvs = new unikvs.Builder().persist(storage).build({ beforeStorage: [new Middleware()] });
```

配列の先頭ほど既存のパイプライン側、末尾ほどストレージ側に近づくように挿入されます。

### 構成の検証 [#builder-is-valid]

`isValid()` は、全体で 1 件以上のストレージに到達し、`fork()` したすべての分岐も 1 件以上のストレージに到達するかどうかを返します。ストレージに到達しない分岐を含む場合は `false` になります。判定は `fork()` 時点の分岐の構成を基準にするため、fork 後に分岐を変更しても結果は変わりません。

```ts
const builder = new unikvs.Builder().persist(mainStorage).fork(new unikvs.Branch());

builder.isValid(); // false
```

## クライアント操作 [#client-operations]

作成したクライアントは次の操作を提供します。`open()` で初期化し、使い終わったら `close()` で閉じます (`await using` でも自動クローズできます)。

| メソッド          | 説明                                               |
| ----------------- | -------------------------------------------------- |
| `open()`          | ストレージとミドルウェアを初期化します。           |
| `close()`         | すべてのストレージとミドルウェアをクローズします。 |
| `set(key, value)` | キーに値を保存します。                             |
| `get(key)`        | キーから値を取得します。                           |
| `stream(key)`     | キーからストリームを取得します。                   |
| `has(key)`        | キーが存在するかを確認します。                     |
| `delete(key)`     | キーを削除します。                                 |
| `clear()`         | すべてのデータを削除します。                       |

すべての操作は `AbortSignal` によるキャンセルと、実行時変数 (`vars`) の受け渡しに対応します。引数はオプションオブジェクト形式と位置引数形式のどちらでも指定できます。

```ts
const ac = new AbortController();
setTimeout(() => ac.abort(), 1000);

await kvs.set("foo", new Uint8Array([0, 1, 2]), {
  signal: ac.signal,
  vars: { traceId: "abc-123" },
});

const bytes = await kvs.get("foo", { signal: ac.signal });
```

## 値の型 [#value-types]

`PlainValue`・`StreamValue`・`Value` は型と関数の両方です。型として使うとキーごとに使えるメソッドを制限し、関数として使うと Valibot スキーマから型を推論します。

| 型               | 書き込み                           | 読み取り      | ストリーム読み取り            |
| ---------------- | ---------------------------------- | ------------- | ----------------------------- |
| `PlainValue<T>`  | `set(key, T)`                      | `get(key): T` | 不可。                        |
| `StreamValue<T>` | `set(key, T \| ReadableStream<T>)` | 不可。        | `stream(key): ValueStream<T>` |
| `Value<T>`       | `set(key, T \| ReadableStream<T>)` | `get(key): T` | `stream(key): ValueStream<T>` |

`Value<T>` は両方に対応する糖衣構文で、`PlainValue<T> | StreamValue<T>` と等価です。

<Tabs>
  <Tab title="型で指定">
    ```ts
    import * as unikvs from "unikvs";

    const kvs = new unikvs.Builder<{
      message: unikvs.PlainValue<string>;
      logs: unikvs.StreamValue<Uint8Array>;
    }>()
      .persist(storage)
      .build();

    await kvs.open();

    await kvs.set("message", "hello");
    const msg = await kvs.get("message");
    // msg は string 型になります

    await kvs.set("logs", new Uint8Array([0x01]));
    const valueStream = await kvs.stream("logs");
    ```

  </Tab>
  <Tab title="スキーマで指定">
    ```ts
    import * as unikvs from "unikvs";
    import * as v from "valibot";

    const kvs = new unikvs.Builder({
      schema: {
        message: unikvs.PlainValue(v.string()),
        logs: unikvs.StreamValue(v.instance(Uint8Array)),
      },
    })
      .persist(storage)
      .build();

    await kvs.open();

    await kvs.set("message", "hello");
    const msg = await kvs.get("message");
    // msg は string 型になります
    ```

  </Tab>
</Tabs>

許可されていない組み合わせは型エラーです。`schema` ありの場合は、実行時にも `InvalidInputError` を投げます。

```ts
// 型エラー: PlainValue のキーに stream() は使えません
kvs.stream("message");

// 型エラー: StreamValue のキーに get() は使えません
kvs.get("logs");
```

## スキーマによる検証 [#schema-validation]

`schema` を指定すると、入出力値を Valibot スキーマで検証します。

| 操作            | 検証内容                               | 失敗時のエラー       |
| --------------- | -------------------------------------- | -------------------- |
| `set`           | 入力値を検証します。                   | `InvalidInputError`  |
| `get`           | 出力値を検証します。                   | `InvalidOutputError` |
| `stream`        | チャンクを 1 つずつ検証します。        | `InvalidOutputError` |
| `has`・`delete` | 配列形式の場合のみ、キーを検証します。 | `InvalidInputError`  |

```ts
import * as unikvs from "unikvs";
import * as v from "valibot";

const kvs = new unikvs.Builder({
  schema: {
    message: unikvs.PlainValue(v.pipe(v.string(), v.minLength(1))),
  },
})
  .persist(storage)
  .build();

await kvs.open();

await kvs.set("message", "hello");
await kvs.get("message"); // "hello"

// 入力検証に失敗し、InvalidInputError を投げます
await kvs.set("message", "");
```

:::note[プレーンとストリームの取り違え]
プレーン専用のキーに `ReadableStream` を渡した場合や、ストリーム専用のキーにプレーン値を渡した場合は `InvalidInputError` を投げます。配列形式でどのキースキーマにも一致しないキーも `InvalidInputError` です。
:::

## ValueStream [#value-stream]

`stream()` の戻り値は `ValueStream<T>` で、`ReadableStream` のラッパーです。`for await...of` と `await using` による自動破棄に対応します。

<Tabs>
  <Tab title="getReader">

```ts
const reader = (await kvs.stream("logs")).getReader();
while (true) {
  const { done, value } = await reader.read();
  if (done) {
    break;
  }
  console.log(value); // Uint8Array
}
```

  </Tab>
  <Tab title="for-await">

```ts
for await (const chunk of await kvs.stream("logs")) {
  console.log(chunk); // Uint8Array
}
```

  </Tab>
  <Tab title="await using">

```ts
await using valueStream = await kvs.stream("logs");
const reader = valueStream.getReader();
const { value } = await reader.read();
console.log(value);
```

  </Tab>
</Tabs>

:::warning[使い終わったストリームは破棄してください]
`await using` による自動破棄か `dispose()` を忘れないでください。
:::

## 変数とキャンセル [#variables-and-cancellation]

`vars` で操作ごとの設定を渡します。

```ts
const kvs = new unikvs.Builder<{ foo: unikvs.Value<Uint8Array> }>().persist(storage).build();

await kvs.open();

// 操作ごとに vars を渡します
await kvs.set("foo", new Uint8Array([1]), {
  vars: { region: "us-east-1" },
});

// 配列形式でも指定できます
await kvs.get("foo", {
  vars: [["region", "us-east-1"]],
});
```

キャンセルは `AbortSignal` で行い、中断した操作は理由とともに失敗します。

```ts
const ac = new AbortController();
setTimeout(() => ac.abort(), 1000);

await kvs.set("foo", new Uint8Array([1]), { signal: ac.signal });
```

## 基本 vars [#base-vars]

`new Builder({ vars })` で基本 vars を設定します。各操作の `vars` と結合して使われ、操作側のキーが勝ちます。`Record`・`Map`・エントリー配列・`Variables` のいずれでも指定できます。不正な形式は `InvalidInputError` を投げます。

```ts
const kvs = new unikvs.Builder<{ foo: unikvs.Value<Uint8Array> }>({
  vars: { region: "us-east-1" },
})
  .persist(storage)
  .build();

await kvs.open();

// 操作側の vars と結合します。操作側の `region` が勝ちます
await kvs.set("foo", new Uint8Array([1]), {
  vars: { region: "eu-west-1", traceId: "abc-123" },
});
// 実行時変数は { region: "eu-west-1", traceId: "abc-123" } になります
```

`build()` は呼び出し時点の基本 vars をスナップショットします。ビルダーの再利用は可能で、後からビルダーを変更しても作成済みのクライアントには影響しません。

ビルダー (`Builder`) とクライアント (`UniKvs`) の両方に、基本 vars を変更する同名メソッドがあります。いずれも自身を返すため、メソッドチェーンできます。クライアント側の変更は以降の操作から有効になります。

### `setVars` [#base-vars-set-vars]

基本 vars を丸ごと置き換えます。

```ts
builder.setVars({ region: "us-east-1" });
kvs.setVars({ region: "us-east-1" });
```

### `assignVars` [#base-vars-assign-vars]

引数の `vars` で基本 vars を上書きします。引数に含まれるキーが勝ちます。

```ts
// 基本 vars が { a: 1, b: 2 } のとき
builder.assignVars({ b: 20, c: 3 });
// 基本 vars は { a: 1, b: 20, c: 3 } になります
```

### `defaultsVars` [#base-vars-defaults-vars]

引数の `vars` をベースに基本 vars で上書きします。現在の基本 vars に含まれるキーが勝ちます。

```ts
// 基本 vars が { a: 1, b: 2 } のとき
builder.defaultsVars({ b: 20, c: 3 });
// 基本 vars は { a: 1, b: 2, c: 3 } になります
```

## 読み取り時の書き戻し [#read-repair]

`get` と `stream` は `repair: true` を指定すると、後段のストレージで見つかった値を前段のストレージへ書き戻します (既定は `false`)。書き戻しが拒否されても既定では読み取りは成功し、警告ログに残ります。拒否時に読み取りも失敗させる場合は `throwOnRepairDenied: true` を指定します (既定は `false`)。書き戻しの可否は [`@unikvs/allow-repair`](/packages/allow-repair) で制御し、拒否時の `meta.names` に書き戻し先の表示名が入ります。詳細は[複数の保存先を使う](/how-to/multi-storage)を参照してください。

```ts
const bytes = await kvs.get("foo", { repair: true });
```

## エラー [#errors]

| エラークラス                       | 説明                                    |
| ---------------------------------- | --------------------------------------- |
| `KeyNotFoundError`                 | キーがどのストレージにもありません。    |
| `UniKvsIsNotOpenError`             | 未オープンで操作しました。              |
| `UniKvsIsOpenError`                | オープン済みで再度 `open()` しました。  |
| `MissingStorageError`              | ストレージ未登録で `build()` しました。 |
| `StorageIsNotOpenError`            | ストレージが未オープンです。            |
| `TransformerIsNotOpenError`        | ミドルウェアが未オープンです。          |
| `PluginOperationAggregateError`    | 複数プラグイン操作の集約エラーです。    |
| `InvalidInputError`                | 入力形式が不正です。                    |
| `InvalidOutputError`               | 出力形式が不正です。                    |
| `ReadableStreamNotSupportedError`  | 読み取りストリーム未対応です。          |
| `WritableStreamNotSupportedError`  | 書き込みストリーム未対応です。          |
| `EncodableStreamNotSupportedError` | エンコード用ストリーム未対応です。      |
| `DecodableStreamNotSupportedError` | デコード用ストリーム未対応です。        |

```ts
import * as unikvs from "unikvs";

try {
  const bytes = await kvs.get("missing-key");
} catch (ex) {
  if (ex instanceof KeyNotFoundError) {
    console.log("キーが見つかりません");
  } else {
    throw ex;
  }
}
```

エラーの分類や対処は、[エラーを処理する](/how-to/handle-errors)を参照してください。

## 使用例 [#examples]

`@unikvs/memory` を使った最小例です。

<Tabs>
  <Tab title="最小例">
    ```ts
    import { Memory } from "@unikvs/memory";
    import * as unikvs from "unikvs";

    const kvs = new unikvs.Builder<{
      foo: unikvs.Value<Uint8Array>;
    }>()
      .persist(new Memory())
      .build();

    await kvs.open();

    await kvs.set("foo", new Uint8Array([0, 1, 2]));

    const bytes = await kvs.get("foo");
    console.log(bytes); // Uint8Array(3) [0, 1, 2]

    console.log(await kvs.has("foo")); // true

    await kvs.delete("foo");
    await kvs.close();
    ```

  </Tab>
  <Tab title="検証あり">
    ```ts

    ```
