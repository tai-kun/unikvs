## 概要 [#overview]

`@unikvs/indexeddb` <Badge variant="warning">ブラウザー専用</Badge> は IndexedDB に任意の値を保存するストレージです。構造化複製できる値や `Blob`・`File` を保存したい場合に使います。

- `name` は `Indexeddb` です。
- `open`・`close` が必要です。
- データベース名とストア名はコンストラクターで指定します。
- `Blob`・`File` は中間形式で保存し、読み戻し時に復元します。

インストールは次のコマンドで行います。

```package-install
npm install @unikvs/indexeddb
```

## 使い方 [#usage]

Indexeddb は IStorage を実装しています。UniKvs には persist() で渡します。

```ts
import { Indexeddb } from "@unikvs/indexeddb";
```

コンストラクターの引数は次のとおりです。

<TypeTable
  type={{
    dbName: {
      type: "[#db-name] string",
      default: '"unikvs_db"',
      description: "使うデータベースの名前です。",
    },
    storeName: {
      type: "[#store-name] string",
      default: '"kvs_store"',
      description: "使うオブジェクトストアの名前です。",
    },
  }}
/>

以下は、値を保存して読み戻す例です。

```ts
import { Indexeddb } from "@unikvs/indexeddb";
import * as unikvs from "unikvs";

const kvs = new unikvs.Builder<{
  greeting: unikvs.PlainValue<string>;
}>()
  .persist(new Indexeddb())
  .build();

await kvs.open();
await kvs.set("greeting", "hello");

const value = await kvs.get("greeting");
console.log(value); // "hello"

await kvs.close();
```

## データ型 [#data-types]

| 操作                                    | 対応するデータ型                      |
| --------------------------------------- | ------------------------------------- |
| `write`・`read`                         | 任意の値（`Blob`・`File` を含みます） |
| `getWritable`・`getReadable` のチャンク | `Uint8Array`                          |

- 任意の値を保存できます。IndexedDB の構造化複製に対応した値を扱います。
- `Blob`・`File` は中間形式で保存し、読み戻し時に復元します。`File` の名前と更新時刻も保持します。
- 存在しないキーに対する `delete` は成功し、`exists` は `false` を返します。
- ストリームのチャンクは `Uint8Array` です。
- `getWritable` で取得したストリームは、チャンクを結合し、`close` 時に保存します。
- `getReadable` で取得したストリームは、保存値を単一チャンクとして送出します。

## エラー [#errors]

このパッケージ固有のエラーはありません。見つからないキーを読み取ると `NotFoundError` の `DOMException` が投げられます。未オープン時に操作すると `TypeError` が投げられます。
