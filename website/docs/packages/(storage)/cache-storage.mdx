## 概要 [#overview]

`@unikvs/cache-storage` <Badge variant="warning">ブラウザー専用</Badge> は Cache API に `Response` を保存するストレージです。取得した応答をそのまま蓄えたい場合に使います。

- `name` は `CacheStorage` です。
- `open`・`close` が必要です。`open` は `Cache` を開きます。
- 論理キーから `Request` への変換は `toRequest` で指定します。
- 専用の `Cache` を使うので、`clear` は列挙した要求をすべて削除します。

インストールは次のコマンドで行います。

```package-install
npm install @unikvs/cache-storage
```

## 使い方 [#usage]

CacheStorage は IStorage を実装しています。UniKvs には persist() で渡します。

```ts
import { CacheStorage } from "@unikvs/cache-storage";
```

コンストラクターの引数は次のとおりです。

<TypeTable
  type={{
    cacheName: {
      type: "[#cache-name] string",
      required: true,
      description: "使う Cache の名前です。",
    },
    toRequest: {
      type: "[#to-request] IToRequest",
      required: true,
      description: "論理キーを Request に変換する関数です。",
    },
    caches: {
      type: "[#caches] CacheStorage | undefined",
      description:
        "使う Cache API の CacheStorage です。省略した場合は実行環境の Cache API を使います。",
    },
  }}
/>

以下は、`Response` を保存して読み戻す例です。

```ts
import { CacheStorage } from "@unikvs/cache-storage";
import { UniKvs, type PlainValue } from "unikvs";

const kvs = UniKvs.config<{
  page: PlainValue<Response>;
}>()
  .persist(
    new CacheStorage({
      cacheName: "unikvs",
      toRequest: (key) => `/kvs/${key}`,
    }),
  )
  .create();

await kvs.open();
await kvs.set("page", new Response("hello"));

const res = await kvs.get("page");
console.log(await res.text()); // "hello"

await kvs.close();
```

## データ型 [#data-types]

| 操作                                    | 対応するデータ型          |
| --------------------------------------- | ------------------------- |
| `write`・`read`                         | `Response`                |
| `getWritable`・`getReadable` のチャンク | `Uint8Array<ArrayBuffer>` |

- `Response` をそのまま保存します。
- ストリームのチャンクは `Uint8Array<ArrayBuffer>` のみに対応します。
- `getWritable` で取得したストリームは、チャンクを結合し、`close` 時に `Response` として保存します。
- `getReadable` で取得したストリームは、保存した `Response` のバイト列を単一チャンクとして送出します。

## エラー [#errors]

このパッケージが投げるエラーは次のとおりです。

### KeyNotFoundError [#key-not-found-error]

#### 意味

指定したキーが存在しない場合に投げます。`@unikvs/core` の共通エラーです。

#### 対処方法

`exists` で確認してから読み出してください。

#### 例

以下は、`KeyNotFoundError` を捕捉する例です。

```ts
import { KeyNotFoundError } from "@unikvs/cache-storage";

try {
  await kvs.get("missing-key");
} catch (ex) {
  if (ex instanceof KeyNotFoundError) {
    console.log("キーが見つかりません");
  } else {
    throw ex;
  }
}
```

### CacheStorageNotAvailableError [#cache-storage-not-available-error]

#### 意味

`open` 時に Cache API が見つからない場合に投げます。注入された `caches` がなく、実行環境にも Cache API がありません。

#### 対処方法

`options.caches` に `CacheStorage` を注入するか、対応するブラウザーで使ってください。

### InvalidChunkTypeError [#invalid-chunk-type-error]

#### 意味

`getWritable` に `Uint8Array<ArrayBuffer>` 以外のチャンクを書き込んだ場合に投げます。

#### 対処方法

ストリームには `Uint8Array` のチャンクを書き込んでください。
