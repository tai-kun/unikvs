UniKVS consists of the core `unikvs` package plus plugin and utility packages. Install everything except `unikvs` only as needed.

See [installation](/how-to/installation) for setup, and [storage comparison](/reference/comparison) for choosing a backend.

## Middleware [#middleware]

Transparently transform values. Grouped by transformation.

<CardGroup cols={2}>
  <Card title="@unikvs/json" href="./json" icon="braces">
    Convert values to JSON, and to JSON Lines for streams.
  </Card>
  <Card title="@unikvs/superjson" href="./superjson" icon="boxes">
    Convert with SuperJSON, preserving Date, Map, Set, BigInt, and undefined.
  </Card>
  <Card title="@unikvs/cbor" href="./cbor" icon="binary">
    Convert values to CBOR, and to CBOR sequences for streams.
  </Card>
  <Card title="@unikvs/v8-serde" href="./v8-serde" icon="binary">
    Serialize fast with Node.js v8.serialize.
  </Card>
  <Card title="@unikvs/base64" href="./base64" icon="file-code">
    Convert bytes to Base64 text.
  </Card>
  <Card title="@unikvs/base64url" href="./base64url" icon="file-code">
    Convert bytes to URL-safe Base64url.
  </Card>
  <Card title="@unikvs/hex" href="./hex" icon="file-code">
    Convert bytes to hexadecimal (Hex) strings.
  </Card>
  <Card title="@unikvs/compression" href="./compression" icon="archive">

  <Card title="@unikvs/checksum" href="./checksum" icon="shield-check">

  <Card title="@unikvs/zstd.bun" href="./zstd-bun" icon="archive">

  <Card title="@unikvs/brotli.node" href="./brotli-node" icon="archive">

## Dev tools [#dev]

<CardGroup cols={2}>
  <Card title="@unikvs/debug" href="./debug" icon="bug">

  </Card>
  <Card title="@unikvs/passthrough" href="./passthrough" icon="arrow-right-left">
    Pass data through without transformation.
  </Card>
  <Card title="@unikvs/tap" href="./tap" icon="hand-pointer">
    Pass data through while invoking a callback with the context.
  </Card>
  <Card title="@unikvs/allow-repair" href="./allow-repair" icon="wrench">
    Control whether read-repair write-backs are allowed.
  </Card>

  </Card>
  <Card title="@unikvs/writeonly" href="./writeonly" icon="lock">

  <Card title="@unikvs/readonly" href="./readonly" icon="lock">
