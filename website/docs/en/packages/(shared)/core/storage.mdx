## Overview [#overview]

`IStorage` is the interface destination plugins implement. It has `name`, `isOpen`, and CRUD operations; lifecycle and stream acquisition are optional. Four type arguments tune data and chunk types.

```ts
import type { IStorage } from "@unikvs/core";

type BinaryStorage = IStorage<Uint8Array>;
type ObjectStorage = IStorage<{ readonly id: number }>;
type FullStorage = IStorage<Uint8Array, string, ArrayBuffer, number>;
```

## Type arguments [#type-params]

| Type argument | Default       | Corresponding operation    |
| ------------- | ------------- | -------------------------- |
| `TWriteData`  | `any`         | `data` of `write(c, data)` |
| `TReadData`   | `TWriteData`  | return of `read(c)`        |
| `TWriteChunk` | `any`         | chunk of `getWritable(c)`  |
| `TReadChunk`  | `TWriteChunk` | chunk of `getReadable(c)`  |

`TReadData` defaults to `TWriteData`, and `TReadChunk` defaults to `TWriteChunk`. When read/write types match, specify only the data type argument (`TWriteData`); when you use no streams, omit the chunk type arguments.

```ts
// writes are bytes, reads are strings
type TextReadStorage = IStorage<Uint8Array, string>;

// specify down to chunks
type ChunkedStorage = IStorage<Uint8Array, string, ArrayBuffer, number>;
```

For the chunk/stream-type relationship, see [Streams](./stream#chunks).

## Identity [#identity]

| Member   | Required | Description         |
| -------- | -------- | ------------------- |
| `name`   | required | Plugin name         |
| `isOpen` | required | Whether initialized |

`open(c)` and `close(c)` are optional. Implement them only when you need setup or teardown. Callers check state via `isOpen`.

## CRUD [#crud]

| Member   | Required | Signature                                                   | Description          |
| -------- | -------- | ----------------------------------------------------------- | -------------------- |
| `write`  | required | `(c: WriteContext, data: TWriteData) => MaybePromise<void>` | Stores data          |
| `read`   | required | `(c: ReadContext) => MaybePromise<TReadData>`               | Fetches data         |
| `exists` | required | `(c: ExistsContext) => MaybePromise<boolean>`               | Returns key presence |
| `delete` | required | `(c: DeleteContext) => MaybePromise<void>`                  | Deletes a key        |
| `clear`  | required | `(c: ClearContext) => MaybePromise<void>`                   | Deletes all data     |

Every method returns `MaybePromise` (`T | PromiseLike<T>`), so sync and async implementations both work.

:::warning[Missing keys throw]
`read` throws [`KeyNotFoundError`](./errors#error-key-not-found) for missing keys. Do not return `undefined` or embed an `exists`-like check; leave post-missing handling (such as read-time repair) to the caller.
:::

## Stream acquisition [#streams]

| Member        | Required | Signature                                                               | Description                |
| ------------- | -------- | ----------------------------------------------------------------------- | -------------------------- |
| `getWritable` | optional | `(c: GetWritableContext) => MaybePromise<IWritableStream<TWriteChunk>>` | Acquires a writable stream |
| `getReadable` | optional | `(c: GetReadableContext) => MaybePromise<IReadableStream<TReadChunk>>`  | Acquires a readable stream |

Storages without stream support omit the implementation. Support is detected by runtime presence, not by types, so unimplemented operations must stay absent rather than throwing "unsupported".

:::note[Reject when aborted before start]
When called with an already-aborted signal, fail immediately with [`StorageAbortedError`](./errors#error-storage-aborted). See [Streams › Stream acquisition](./stream) and the stream example below.
:::

## Multi-storage writes [#other-write-error]

| Member              | Required | Description                                               |
| ------------------- | -------- | --------------------------------------------------------- |
| `onOtherWriteError` | optional | Receives other storages' failures on multi-storage writes |

Arguments are `(c: OtherWriteErrorHandlerContext, errors: readonly IOtherWriteError[])`. `OtherWriteErrorHandlerContext` is `WriteContext | GetWritableContext`, indicating which write path failed.

`IOtherWriteError` has the following shape:

## Context aliases [#contexts]

The `IStorage` namespace provides aliases of [pipeline contexts](./pipeline-context#contexts). Using `IStorage.*` on the plugin side clarifies intent.

| Alias                                    | Entity                                                | Used by             |
| ---------------------------------------- | ----------------------------------------------------- | ------------------- |
| `IStorage.OpenContext`                   | [`IOpenContext`](./pipeline-context#iopencontext)     | `open`              |
| `IStorage.CloseContext`                  | [`ICloseContext`](./pipeline-context#iclosecontext)   | `close`             |
| `IStorage.WriteContext`                  | [`ISetContext`](./pipeline-context#isetcontext)       | `write`             |
| `IStorage.GetWritableContext`            | [`ISetContext`](./pipeline-context#isetcontext)       | `getWritable`       |
| `IStorage.ReadContext`                   | [`IGetContext`](./pipeline-context#igetcontext)       | `read`              |
| `IStorage.GetReadableContext`            | [`IStreamContext`](./pipeline-context#istreamcontext) | `getReadable`       |
| `IStorage.ExistsContext`                 | [`IHasContext`](./pipeline-context#ihascontext)       | `exists`            |
| `IStorage.DeleteContext`                 | [`IDeleteContext`](./pipeline-context#ideletecontext) | `delete`            |
| `IStorage.ClearContext`                  | [`IClearContext`](./pipeline-context#iclearcontext)   | `clear`             |
| `IStorage.OtherWriteErrorHandlerContext` | `WriteContext \| GetWritableContext`                  | `onOtherWriteError` |

## Example [#example]

<Tabs>
  <Tab title="Sync">
    ```ts
    import {
      KeyNotFoundError,
      type IStorage,
    } from "@unikvs/core";

    export class Memory implements IStorage<string> {
      public readonly name = "Memory";
      public isOpen = false;
      private readonly data = new Map<string, string>();

      public open(): void {
        this.isOpen = true;
      }

      public close(): void {
        this.isOpen = false;
      }

      public write(c: IStorage.WriteContext, value: string): void {
        this.data.set(c.key, value);
      }

      public read(c: IStorage.ReadContext): string {
        const value = this.data.get(c.key);
        if (value === undefined) {
          throw new KeyNotFoundError({ key: c.key });
        }
        return value;
      }

      public exists(c: IStorage.ExistsContext): boolean {
        return this.data.has(c.key);
      }

      public delete(c: IStorage.DeleteContext): void {
        this.data.delete(c.key);
      }

      public clear(): void {
        this.data.clear();
      }
    }
    ```

  </Tab>
  <Tab title="Async">
    ```ts
    import {
      KeyNotFoundError,

    export class AsyncMemory implements IStorage<string> {
      public readonly name = "AsyncMemory";
      public isOpen = false;
      private readonly data = new Map<string, string>();

      public async open(): Promise<void> {
        this.isOpen = true;
      }

      public async close(): Promise<void> {
        this.isOpen = false;
      }

      public async write(c: IStorage.WriteContext, value: string): Promise<void> {
        this.data.set(c.key, value);
      }

      public async read(c: IStorage.ReadContext): Promise<string> {
        const value = this.data.get(c.key);
        if (value === undefined) {
          throw new KeyNotFoundError({ key: c.key });
        }
        return value;
      }

      public async exists(c: IStorage.ExistsContext): Promise<boolean> {
        return this.data.has(c.key);
      }

      public async delete(c: IStorage.DeleteContext): Promise<void> {
        this.data.delete(c.key);
      }

      public async clear(): Promise<void> {
        this.data.clear();
      }
    }
    ```

  </Tab>
</Tabs>

Implementation points:

<Steps>
  <Step title="Pick type arguments">
    Declare the stored value type as `IStorage<T>`. When read/write types differ or you use streams, specify all four.
  </Step>
  <Step title="Implement required members">
    `name`, `isOpen`, and the 5 CRUD methods are required. `read` throws `KeyNotFoundError` for missing keys.
  </Step>
  <Step title="Add optional members">
    Implement `open` / `close` only with setup needs, `getWritable` / `getReadable` for streams, and `onOtherWriteError` when you need other storages' failure reports.
  </Step>
</Steps>
