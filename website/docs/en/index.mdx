UniKVS is a modular, portable KVS client for TypeScript. It combines middleware that transparently transforms data with storages that write to multiple backends, assembled through a builder.

## Quickstart [#quickstart]

Start with the minimal in-memory setup. It takes about 5 minutes.

```ts
import { Memory } from "@unikvs/memory";
import * as unikvs from "unikvs";

const kvs = new unikvs.Builder<{
  greeting: unikvs.PlainValue<string>;
}>()
  .persist(new Memory())
  .build();

await kvs.open();
await kvs.set("greeting", "hello");

const value = await kvs.get("greeting");
console.log(value); // "hello"

await kvs.close();
```

See [Your First UniKVS](/tutorials/first-kvs) for the full walkthrough.

## Key Features [#features]

- Transparent encoding and decoding via middleware.
- Parallel writes to multiple storages.
- Per-key value types that restrict available operations at the type level.
- Runtime validation of input/output values with Valibot schemas.
- Support for both single values and streams.
- Cancellation via `AbortSignal` and per-operation runtime variables.
- Storages for both Node.js and browsers.
