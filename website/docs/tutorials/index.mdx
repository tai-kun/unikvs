初めて UniKVS に触る方は、このセクションから進めてください。実際に動くものを作りながら、最小限の概念だけを身につけます。

## このセクションで学ぶこと [#what-you-learn]

- インストールから読み書きまでの最短経路を確認します。
- `Builder` と `persist()` と `build()` の関係をつかみます。
- `open()` と `close()` の基本的な使い方を覚えます。
